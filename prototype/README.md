# BabyPlan 三端低保真原型

更新：2026-11-12。安卓端 N01—N12、网页家长区 W01—W08、内容管理区 C01—C06 使用同一虚构样本，分别在浏览器内模拟流程。用于评审信息层级、文案和状态；不是可交付 App，也不是接口实现。实际检查与未覆盖项见 [网页验证记录](验证记录.md)。

## 网页入口与启动

总入口为 [prototype/index.html](index.html)，网页家长区为 [parent/index.html](parent/index.html)，内容管理区为 [admin/index.html](admin/index.html)。可直接打开HTML；如果浏览器拦截本地脚本，请从项目根目录启动：

```bash
python -I tools/serve_prototype.py --surface all --port 4174
```

访问 `http://127.0.0.1:4174`，家长区 `/parent/`，管理区 `/admin/`，安卓端 `/mobile/`。Code 预览配置为「BabyPlan 三端低保真」。服务只提供 `prototype/` 静态文件，仅监听本机，不含API或上传接口；评审文件禁止缓存以便查看最新修改。

网页两区各自包含 `index.html`、`styles.css` 和 `app.js`，都从 `../mobile/fixture.js` 读取 `window.BABYPLAN_FIXTURE`。请保留目录结构；更新扩展数据后运行 `tools/build_mobile_prototype.py`。三端使用同一份初始数据，各端内存修改不会跨端、跨标签或刷新后同步。

| 区域 | 页面与代表流程 | 评审重点 |
| --- | --- | --- |
| 家长网页 | W01连接、W02今天与本周、W03调整、W04阶段、W05书架、W06成长、W07打印、W08设置 | 调整按内容块确认；周内未提供的日期不编造安排；照片待上传不进打印预览；无管理发布权限 |
| 内容管理 | C01角色、C02内容库、C03草稿、C04审核、C05发布、C06版本与撤回 | 草稿与家庭安排分开；角色为候选；审核通过不等于发布；发布失败不改活跃版本；撤回影响未决 |

书目版本、阶段来源、测量方法与参考标准仍需审阅。所有照片都是占位；无曲线、百分位或发育评分。打印只展示本地静态预览，不生成正式PDF、上传或发送文件。发布与撤回只修改管理原型内存，不会改变家长页或历史安排。

现有OpenAPI仍是v0.1一日一卡M1/M2，不能直接接受这些扩展对象。正式开发先评审并统一升级业务规格、OpenAPI、Schema与校验，不从原型事件名推导API路径。静态页面可作为React/Web的信息结构参考；安卓仍需按Flutter语义、系统字号与TalkBack重新实现和验收。

组件采用本地系统字体、灰阶变量、文字状态标签、可换行按钮、原生表单和dialog，低保真无第三方插画、封面、字体或图标授权依赖。主题、字号和场景控件属于审阅工具，不进入产品导航；颜色、导航、记录粒度和角色权限仍为候选。

## 安卓端说明与历史检查

以下保留安卓首版的打开方式、覆盖与检查记录。

## 1. 打开方式

原型是纯静态 HTML/CSS/JS，无构建步骤、无依赖、无网络请求。三种方式任选：

1. 用浏览器打开 `prototype/mobile/index.html`。脚本均为普通相对路径引用，一般可直接运行；若浏览器拦截本地脚本，改用下面的本地服务方式。
2. 需要固定端口预览时，在项目根目录运行：

```bash
python -I tools/serve_prototype.py --port 4173
```

然后访问 `http://127.0.0.1:4173`。该服务只提供静态文件，没有 API、上传或写入能力，仅监听 `127.0.0.1`。

3. 使用本会话的 `.claude/launch.json` 配置（`BabyPlan 安卓低保真`）启动预览。

「设计审阅面板」不属于产品界面：宽屏时在画布右侧，窄屏时折叠在画布下方。可切换 24 个演示场景、当前添加者、深浅主题、100%/200% 字号，并模拟保存失败与同步状态。

## 5. 已实现与模拟边界

真实实现的是页面结构、文案、状态切换、键盘焦点与本地校验；以下都只是页面内模拟，刷新即丢失：

- 保存、同步、冲突合并、重试、恢复网络、连接恢复；
- 提醒时间与权限限制、发布相关状态；
- 照片占位、上传成功/失败，不打开相册、不读取文件。

明确没有实现：Flutter App、APK、系统通知、SQLite、跨设备同步、真实账号与邀请、媒体存储、参考曲线或百分位、自动排程算法、正式内容审阅。
