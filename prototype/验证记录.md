# 网页低保真原型验证记录

日期：2026-11-12（部分检查始于 2026-11-11）。范围为网页家长区 W01—W08 和内容管理区 C01—C06。记录本地静态原型的实际检查，不等同于正式产品验收。原型内固定时钟仍为 2026-11-11 15:00。

## 验证方式与边界

用桌面 Chromium 实际浏览页面、检查 DOM/计算样式并驱动原型按钮；页面只从本机 `tools/serve_prototype.py` 加载本端 HTML、CSS、JS 与共享虚构数据，网络记录中没有外部地址。固定时钟与虚构数据来自 `content/design/expanded-prototype.json`。修改在各端独立内存中，刷新即重置，不进行真实鉴权、同步、上传、打印或发布。

视口为 1280×900、768×900、360×800；字号 100% 与 200%；浅色和深色灰阶主题。对比度为页面实际计算颜色的相对亮度比值，取每个页面可见正文的最小值。

P12—P18 由下面的路径记录支撑；没有执行的项目写在“未验证项”。P01—P11 的安卓历史检查见 `README.md`，本轮不自动重新判定通过；D 系列旧合同验收不在本轮范围。

## 网页家长区

| 检查项 | 实际结果 |
| --- | --- |
| 连接与家庭（W01） | connected、connecting、expired、failed、not_joined 五种状态可切换；连接中只提供模拟重试，失效提供更新连接与重试，未加入家庭提供重试与加入方式说明；未加入家庭时不显示记录与调整入口 |
| 今天与本周（W02） | 只显示样本中存在的日期；没有日期的日子不伪造内容；加载、加载失败、空安排三种状态可区分，加载失败保留缓存并提示 |
| 安排查看与调整（W03） | 打开一项后可换项、缩短、跳过与恢复；确认前不改变列表；缩短分钟数不超过该项时长；保存后标为待同步 |
| 阶段（W04） | 七段结构与来源说明可展开；未制作阶段显示“内容待补”，不套用旧月龄档内容 |
| 书架（W05） | 可添加、替换与恢复虚构书目；只有书名必填；版本、语言、封面、点读兼容性均标注待核实 |
| 成长（W06） | 默认没有已保存记录；只有显式选择“额外虚构成长样本”才出现第一次、原话与测量记录；类型与日期筛选可用；记录草稿保存后为待同步，成员切换保留原记录人 |
| 打印（W07） | 默认不勾照片、不导出整份成长；待上传照片被排除；预览失败保留已有选择；重试后的预览不含照片占位；切换成员、场景或网络后旧预览失效，需重新生成 |
| 家庭与成员（W08） | 虚构成员可切换；只读权限下隐藏记录与调整操作；退出家庭标注待定 |
| 异常与恢复 | 保存失败保留表单输入；照片待上传与上传失败分别提示，失败时保留缓存内容；未来日期（2026-11-12）只读，没有记录或调整按钮 |
| 宽度 | 1280 双栏、768 与 360 单栏，在 100% 与 200% 字号下均无横向溢出 |
| 无障碍 | 8 个页面在 1280 下：0 个无名称按钮、0 个未关联标签的输入、0 个小于 48px 的可操作目标；跳过导航链接获得焦点时在页面顶部露出；对话框在 360 与 200% 下宽 344px、无横向溢出，打开时焦点落在标题，取消或关闭后回到触发按钮 |
| 对比度 | 浅色主题各页最小 6.05:1；深色主题各页最小 8.16:1 |

## 内容管理区

| 检查项 | 实际结果 |
| --- | --- |
| 角色与权限（C01） | 内容编辑可保存草稿、提交审核；内容审核可审核与退回；内容发布可发布与撤回；只读查看不能编辑或发布；“无管理权限”时内容库被阻止并提示返回角色与连接。切换角色保留当前工作流，只用于设计评审 |
| 草稿编辑（C03） | 必填项与英语四段格式校验会标出字段并聚焦首个错误；保存、取消、提交审核可用；离线时提交审核禁用；模拟失败时输入保留；有未保存修改时离开会弹出“继续编辑／放弃修改并离开”，继续编辑保留输入 |
| 审核（C04） | 三项人工核验未完成时不能通过；退回原因为空时报错、设置 `aria-invalid` 并聚焦原因框；退回原因保留并显示在 C03；编辑角色在审核页看到按钮禁用与权限提示 |
| 发布（C05） | 版本说明为空时报错并聚焦；离线时发布禁用并提示线上版本不变；模拟发布失败后活跃版本不变、说明与草稿保留；再次确认后生成 v2 并更新版本记录 |
| 冲突 | 草稿冲突先显示比较对话框（保留草稿／载入新版本），载入后可保存；发布冲突会显示新的活跃版本（v2）并阻止直接覆盖，重新载入基准后回到草稿编辑 |
| 撤回（C06） | 撤回需填写原因并勾选已阅读影响；任一缺失时报错、设置 `aria-invalid` 并聚焦，不关闭对话框；模拟失败保留原因；成功后活跃版本显示为“无”，不自动回滚历史 |
| 内容库（C02） | 可按全部、草稿、待审核、可发布、已发布、已撤回筛选，也可切换活动与书目；空结果、加载中、加载失败（可模拟重试）、空库与断网状态均可区分 |
| 宽度 | C01—C06 在 1280、768、360 与 100%、200% 字号下均无横向溢出 |
| 无障碍 | 6 个页面 0 个无名称控件、0 个未标注输入、0 个小于 48px 的可操作目标（版本快照折叠标题已补足高度）；比较对话框在 360、200%、深色下宽 336px、无横向溢出，焦点落在标题，取消后回到触发按钮 |
| 对比度 | 浅色主题各页最小 6.05:1；深色主题各页最小 8.16:1 |
