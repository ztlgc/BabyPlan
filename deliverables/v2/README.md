- 根目录`打开设计.html`：给家长看的总览，双击可看。
- `界面总览.html`及`界面总览.png`：四个手机主流程的设计画板。
- `活动手册.html`：24张活动卡、完整首周与12条阶段支持，可浏览或打印。

- `screens/`：从实际Chromium原型生成的界面截图。
- `structure-check.json`：内容、接口引用与对比度的实际检查结果。
- `browser-check.json`：实际浏览器交互与响应式检查结果。
- `manifest.json`：交付文件清单和SHA-256；ZIP不含`.work`、`.claude`或私人运行配置。
- 上一级`BabyPlan-v2-设计交付包.zip`：解压后打开根目录总览即可。

所有“在线/离线/冲突/发布”均是本机演示。普通网页运行不代表APK、通知、鉴权、媒体上传、后端部署或专业内容审阅已经完成。完整边界见 `docs/v2/07-验证报告.md`。
