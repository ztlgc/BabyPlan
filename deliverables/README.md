# 交付物用途与版本

更新：2026-11-11。本目录包含设计输入、静态视觉提案与校验报告。三端低保真原型源码在 `prototype/` 并已纳入v0.2 ZIP；尚无APK、真实服务或部署产物。

| 文件 | 定位 | 使用方式 |
| --- | --- | --- |
| `BabyPlan-原型设计输入包-v0.2.zip` | 最新扩展需求原型输入 | 解压从 `docs/design/README.md` 开始；含三端低保真源码和总入口 `prototype/index.html`；N/W/C页面、P验收、虚构扩展样本；旧合同独立对照 |
| `BabyPlan-设计交接包-v0.1.zip` | 历史输入快照 | 保留，不覆盖；不含本次三端前置资料，不作为最新生成任务输入 |
| `设计交接包校验报告.md` | 最新本地资料校验 | 记录脚本实际检查范围，非设计稿或产品验收 |
| `BabyPlan-手机应用效果图.png` | 安卓静态概念 | 可比较温和、易读的视觉方向；旧三导航、iOS式外框和完整字段/长页面覆盖须重审 |
| `BabyPlan-网页端效果图.png` | 较早网页概念 | 与其他PNG并列保留，不作为当前页面基线 |
| `BabyPlan-网页前端效果图.png` | 家长网页静态提案 | 共读、多项和成长等扩展未完整覆盖；信息架构需按新简报重做 |
| `BabyPlan-网页后台效果图.png` | 内容管理静态提案 | 仅呈现排周/发布概念；自由排周并非已确认主要操作，草稿/审阅/权限/撤回需重新设计 |

PNG由 `.work/` 中绘图脚本生成，不是浏览器截图、可点击HTML或正式设计系统。颜色、图标、插画与导航均未获最终确认。三端扩展需求本身保留，不能因旧图不完整便认定网页和成长档案已被取消。

新ZIP包含文字设计输入、三端静态原型源码、浏览器验证记录、JSON、合同、验证工具和本说明；PNG为非必需本地参考，不随包上传。旧归档资料在ZIP中保留原路径，以维持旧规范引用，阅读顺序由 [设计入口](../docs/design/README.md) 规定。

复建使用 `python -I tools/package_design_handoff.py`。它更新最新v0.2 ZIP和校验报告，保留v0.1 ZIP及PNG。无真实成员、家庭照片、凭证、模型密钥或私人部署配置进入新原型样本。设计工具建项目、上传和生成均尚未执行。
