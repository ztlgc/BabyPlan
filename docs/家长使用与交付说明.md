# BabyPlan 家长使用与交付说明

这份说明面向直接使用，不要求会编程。BabyPlan 有两层用法：

- **先立即打开**：安装局域网调试包，不连接家庭服务也能看到内置活动、离线记录和本机成长记录。
- **家庭同步**：在 Windows 电脑启动私人家庭服务，手机和平板登录同一家庭后共享安排、参与记录、成长照片和提醒设置。

## 1. 已经生成的安装包

安装包在 `releases/v0.1.3/`：

| 文件 | 用途 | 使用边界 |
| --- | --- | --- |
| `BabyPlan_0.1.3_lan-debug.apk` | 同一 Wi-Fi 下第一次试用；允许连接 `http://电脑IP:4318/v2` | 使用 Android 调试签名；不要当作公开商店版本 |
| `BabyPlan_0.1.3_private-release.apk` | 已有 HTTPS 家庭服务时使用；使用持久签名 | 只接受 HTTPS 家庭服务地址 |
| `BabyPlan-0.1.3-windows-service.zip` | 在 Windows 电脑解压并安装家庭服务和家长网页 | 仍需 PowerShell 7、Node.js 24 与 PostgreSQL；手机单独使用无需安装 |
| `SHA256SUMS.txt` | 安装包与公开签名证书的完整性校验 | 不要修改下载后的安装包 |
| `release-signature-verification.txt` | Android APK v2 签名验证结果 | 只能证明签名结构，不证明真机运行 |
| `manifest.json` | 版本、包名、大小、证书和验证边界 | 与安装包一起保存 |

手机第一次安装时，如果系统提示允许安装未知来源应用，需要由你明确允许。BabyPlan 不申请整库照片权限，只使用 Android 系统照片选择器读取你主动选中的图片。

## 2. 不连接服务，先打开看看

1. 把 `BabyPlan_0.1.3_lan-debug.apk` 发送到 Android 手机并安装。
2. 打开“小芽 BabyPlan”，从“今天”查看当天安排。
3. 活动详情包含材料、步骤、亲子对话、英语短句和安全提示。
4. 本机模式下列出的内容属于开发/试用数据；可以体验记录、换项、轻松一天、成长与测量、书架和导出流程。
5. 需要同步两位家长时，再按下一节启动私人家庭服务。

## 3. 启动家庭同步服务

解压 `BabyPlan-0.1.3-windows-service.zip`。电脑需要 PowerShell 7、Node.js 24 和 PostgreSQL；脚本会自动安装锁定版本的 Node.js 依赖。进入解压出来的文件夹，在 PowerShell 7 运行：

```powershell
.\scripts\ops\Install-BabyPlan.ps1 -LanAccess
```

安装向导会隐藏输入：

- PostgreSQL 管理员连接；
- 家庭管理员邮箱与称呼；
- 至少 12 位的登录口令；
- 家庭名称、宝宝小名和当前月龄。

完成后会显示两个地址：

```text
手机 API 地址：http://电脑局域网IP:4318/v2
家长网页：http://电脑局域网IP:4174
```

手机和电脑必须连接同一个 Wi-Fi。手机打开“家庭”，填写显示出的 API 地址，再使用安装向导中的家庭管理员邮箱和口令登录。

首次安装记录保存在安装目标目录的 `config/initial-owner.env`，默认位置是解压目录内的 `.work/private/`。这个文件包含登录口令，只保存在这台电脑。局域网向导用的是开发活动，请先用虚构资料体验同步。

Windows 防火墙如果拦截 4174 或 4318，需要在“允许应用通过防火墙”中只放行私人网络。不要在没有 TLS 的情况下把这两个端口映射到公网。

## 4. 让另一位家长加入

1. 家庭管理员在家长网页“家庭设置 → 邀请与加入”或手机“家庭”中创建邀请，并由管理员设置一个 4～32 个字符的邀请码。邀请码 24 小时内有效且只能使用一次。
2. 新家长可以直接打开家长网页，展开登录卡片下方的“有邀请码？创建家长账号”，填写邀请码、邮箱、称呼和至少 12 位密码。创建成功后会自动加入家庭并进入网页。
3. 已有账号的家长先登录网页，再在“家庭设置 → 邀请与加入”中使用“接受另一个家庭的邀请”。Android App 也支持“用邀请创建账号”或登录后接受邀请。
4. 邀请码只消费一次并会过期；加入后双方读取同一家庭安排与参与记录。邀请码全局唯一，用过或过期后请由管理员换一个新的。
5. 跨家庭标识访问在服务端返回 404，不会把另一个家庭的正文返回给当前账号。
6. 同一台手机切换账号时，每个账号使用独立的本机数据库。后登录的人看不到上一位家长尚未同步的草稿，也不会代用上一位家长的操作队列；切回原账号后可以继续同步。

## 5. 每天怎样用

- “今天”只提供建议，不要求做满六项或追补分钟数。家庭服务会按月龄、材料和语言筛选；没有合适的玩法就留空。
- 活动开始后、已经记录后，或家长锁定后，不能从换项页静默覆盖。
- “轻松一天”把四类未开展活动缩短到每项约 5 分钟。已开始、已记录或特意保留的项目仍显示，实际预算可能超过 20 分钟。
- 停止推荐的活动联网核对后不再显示原玩法，原陪伴记录继续保留。离线时会标明可能还没收到最新内容状态。
- 网络中断时，参与、成长和换项先保存在手机本地队列，恢复网络后继续同步。家庭材料和语言设置请在联网时修改；离线改动不能保证已经同步到另一台手机。
- 原话、故事、第一次、测量和阶段观察都可以先在本机更正；错误记录先进入回收站，删除与恢复会以修订和墓碑传播到另一台设备。
- 照片和正文分开保存。照片上传失败不会把已写好的正文一起回滚；设置页显示上传中、待重试和已同步状态。
- 想每天收到提醒，在“家庭 → 提醒”打开开关。默认建议 16:00；可以选 20:00 前的时间。当天都已记录、或系统延迟到 20:00 后，会跳过这次提醒。系统省电可能延迟通知。升级后先打开小芽一次，让新版接管已设置的提醒。

## 6. 内容和安全边界

当前 24 张活动卡来自 `content/candidate/babyplan-18-23-v2.json`，仍是 `candidate/draft / not_reviewed / not_started`。逐项人工审读位置在 [逐卡审读台账](../content/逐卡审读台账.md)。

家长在实际开展前至少应确认：

- 场地、材料和玩具完整，无小零件、线头、松脱附件或夹伤风险；
- 宝宝状态愿意参与；只看、离开或说不要时自然停止；
- 阅读、动作和英语活动不以“学会”或“达标”为目标；
- 对身体动作、材料、发育或医学问题有疑虑时先停用，并咨询相应专业人员。

这份私人试用内容不能描述为专业认证课程或公开发布版本。

## 7. 数据、导出和备份

- 成长记录可以导出 JSON、CSV 和媒体 ZIP；导出下载链接短时有效。
- 永久删除与回收站不同。删除家庭时会先冻结访问，异步清理家庭数据库记录和私有媒体，并保留去标识删除墓碑。
- 数据库和照片必须一起备份。另在受保护的位置保管同一部署的**最新删除台账**，否则不能确认旧备份里已删的内容不会出现。
- 恢复后原账号需要重新登录，原有陪伴者由家庭管理员重新邀请。

完整部署、备份、恢复和升级命令见 [私有部署与备份恢复](ops/私有部署与备份恢复.md)。

## 8. 必须保留的签名资料

持久签名文件位于 `private/android-signing/`，已被 Git 忽略：

- `babyplan-upload.p12`：后续覆盖升级必须继续使用；
- `key.properties`：本机构建读取的签名配置；
- 目录已限制为当前 Windows 用户访问。

请把整个 `private/android-signing/` 备份到受保护的离线位置，并另行保存恢复方法。丢失私钥后，新安装包无法覆盖升级原应用；不要把这个目录放进聊天、公开网盘、Git 仓库或交付 ZIP。

公开证书 `releases/v0.1.3/babyplan-signing-certificate.pem` 可以随安装包分发，它不含私钥。`0.1.3`、`0.1.2` 与 `0.1.0` 的私人 Release 使用同一签名和包名；升级时使用原来的安装包类型，真实手机覆盖升级仍待验证。

## 9. 当前已经验证与尚未验证

已经验证：

- 服务端真实 PostgreSQL 迁移、HTTP 登录、邀请、七天计划、参与更新、成长/照片/导出、内容工作流和账户管理；
- Flutter 静态检查与 90 项 Flutter 测试；其中 1 项真实 HTTP 双手机用例由服务端隔离夹具按需启动，另有 2 项 Android 原生规则测试；
- 同机多账号隔离、成长更正/回收/恢复、真实 HTTP 双手机测量与观察墓碑传播；
- Debug 与持久签名 Release APK 构建；
- Release APK v2 签名、包名、版本、最低/目标 SDK；
- 家长网页 Node 测试与真实 Chromium 双账号同家庭联调；
- 隔离数据库及媒体备份恢复，确认已永久删除的家庭、小记和照片未重新出现。

仍需在真实设备或真实部署环境验证：

- Android 厂商通知送达、锁屏、省电和重启策略；
- 真机系统照片选择器的取消、临时 URI 失效和权限行为；
- 两台真实手机同时同步和网络切换；
- 真实手机切换多个账号后的系统安全存储、进程重启和覆盖升级；
- Windows 防火墙、公网 HTTPS、TLS 证书、生产磁盘和外部备份；
- 24 张活动卡的真实家长审读、必要专业核验和首周家庭试玩。

自动化、原型和接口测试都不能替代这些真实证据。
