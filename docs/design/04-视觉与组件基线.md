# 视觉与组件基线（候选）

日期：2026-11-11；版本：原型准备v0.1。状态：待设计评审，尚未确认为品牌或生产组件库。先完成灰阶低保真；本文件使跨页面方案可比较，不要求先锁定视觉才能开始原型。

## 1. 依据与使用方法

以[扩展需求讨论稿](../BabyPlan-产品与三端架构讨论稿.md)的家长使用场景和[三端简报](05-原型范围与三端简报.md)为依据；现有手机与网页PNG只证明曾提出绿色/米白方向，不能证明对比度、交互或品牌已确认。

候选变量放在 [visual-tokens.json](visual-tokens.json)，标记为 `candidate`。以后调整配色、字阶或间距先改同一文件，确认后另记确认日期；不要让每页另造一套颜色。每轮变体只改一个主变量（布局、字阶或色彩），与同一内容样本比较。

## 2. 候选颜色角色

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| background | #F6F5EF | #17221C | 页面底色 |
| surface | #FFFFFF | #203028 | 卡片、表单、弹层 |
| text | #243D35 | #EDF2EC | 正文、标题 |
| textSecondary | #52665C | #BAC8BC | 日期、说明，不用透明度进一步降低对比 |
| primary / onPrimary | #32684B / #FFFFFF | #A7D0AF / #14291B | 主按钮及其文字、选中操作 |
| error | #9C3029 | #FFB4AB | 错误文字和图标，配具体中文原因 |
| warning | #785014 | #E6C38A | 待同步、权限和风险说明，配状态标签 |
| outline | #718078 | #91A293 | 需要辨识的输入边界和未选控件 |
| dividerDecorative | #DFE5DB | #415147 | 纯装饰分隔；不能承担唯一必要边界 |
| focus | #32684B | #A7D0AF | 外侧焦点环，留2逻辑像素间隙 |

交接脚本校验JSON中声明的前景/背景配对：正文至少4.5:1，必要边界与焦点至少3:1。此项只验证实色组合；最终浏览器中的透明度、图片叠字、悬停和其他表面需另查。记录状态不能只靠颜色，必须同时有“已一起玩 / 今天跳过 / 未记录 / 尚未开始”等文字及可区分图标。

## 3. 排版、间距与响应式

- 系统中文字体；Web栈为 `system-ui, 'Noto Sans CJK SC', 'Microsoft YaHei', sans-serif`，不请求外链字体。Flutter使用平台字体和语义角色，待真机核验回退，不打包未知授权字体。
- 标题26/1.35/600、区块标题20/1.45/600、正文16/1.65/400、控件标签16/1.5/600、辅助说明14/1.55/400。低保真逻辑单位为参考；Android实现映射dp/sp，Web采用rem和可伸缩布局，不把截图像素当sp。
- 间距4/8/12/16/24/32/48；手机左右16、网页左右24，正文最大容器1200。控件圆角8、卡片16、弹层20，弱阴影非必需，优先分组与留白。
- 触控目标至少48×48逻辑单位；标签可换行，不固定按钮文字高度。正文200%字号时允许单列、滚动，主动作不被键盘、底部条或系统手势区遮住。
- 安卓360/412逻辑宽；网页1280参考宽，768和360检查重排。管理表格窄屏可转详情列表，不以缩小字号容纳全部列。主操作每个区域一个，次操作用描边或文字。
- 不固定大卡片高度，不把完整内容塞进一张首屏截图。材料、步骤、家长话术优先；英文/数量等可选段为空则省略，安全说明保持可见。

## 4. 组件与状态约定

| 组件 | 必须交付状态 | 行为/语义 |
| --- | --- | --- |
| 导航与页头 | 当前、未选、返回、窄屏 | 安卓四入口为候选；设置从页头工具入口进入，不计入四入口；管理与家长区明确区分 |
| 主/次/文字按钮 | 默认、按下、焦点、禁用、加载、失败后可重试 | 加载保持按钮宽度并显示“正在保存…”；禁用说明原因，键盘可操作 |
| 单选/多选标签 | 未选、选中、不可用、错误 | 文字和图标同时说明；单选与多选不混用，关联可见标签 |
| 内容卡 | 有材料/不用道具、完整/核心字段、已记/未来；撤回后的家庭卡片外观待定 | 标题→材料→步骤→四类回应→可选扩展→安全和来源；演示标识保留，不默认移除历史 |
| 当天分段 | 未开始、部分已记、已记、临时缩短、无可用内容 | 预算可调整；不显示强制计时、连续奖励或催促凑时长 |
| 输入与校验 | 空值、编辑、非法值、只读、保存中、失败保留 | 持久标签，错误放字段附近并可朗读；不只用红框 |
| 底部表单/确认弹层 | 编辑、取消确认、提交中、失败、冲突 | 焦点进入与恢复；系统返回符合退出规则；长内容可滚动 |
| 状态条 | 已存本机、发送中、失败、同步成功、权限关闭 | 成功不能覆盖更晚本地意图；可进入恢复详情 |
| 空态/错误页 | 真空、加载、网络失败、连接失效、无权限 | 各自文案和恢复入口；失败不能渲染成无内容 |
| 媒体占位 | 未选、已选待上传、上传中、失败、完成、无访问权 | 原型只用色块/图标和“照片占位”，不伪造上传成功 |
| 测量记录 | 空、输入、非法单位/值、表格、无参考资料 | 先录入日期/数值/单位/方式；趋势与参考分开，禁止伪造百分位 |
| 审核发布 | 草稿、待审、需修改、可发布、发布中、发布成功、失败、撤回确认 | 权限和影响范围可见；成功是模拟，草稿不显示在家庭安排 |

## 6. 审阅记录与可访问性验收

低保真结束记录页面ID、路径、状态、候选选择与待改项；高保真再记录变量版本、主题、逻辑宽度、字号倍率、文字/背景实际对比度。检查键盘顺序、焦点可见、弹层焦点恢复、错误可朗读、颜色之外的状态提示。TalkBack、系统权限、通知、离线数据库和真实上传在原生/服务实现后验收。

可选过渡150ms；减少动态效果时0ms，信息不依赖动画。普通装饰分隔与禁用外观不充当唯一状态信息。本轮未制作UI、未进行浏览器视觉验收；变量结构及实色对比度由交接脚本复验。
