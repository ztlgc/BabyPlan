# 安卓应用设计简报

> 范围标识（2026-11-11）：本文保留v0.1一日一卡、单设备开发基线。最新扩展需求原型默认使用 [原型范围与三端简报](05-原型范围与三端简报.md) 和N/W/C页面，不直接使用本文末尾提示词；扩展需求不受本文“无成长档案/管理后台”的旧范围限制，正式接口尚未升级。

版本 v0.1；2026-11-11。产品：BabyPlan / 家庭亲子活动跟踪。中文，安卓手机，用户是家长，活动在线下进行。

## 1. 目标与边界

一个家庭、一台手机，每天一项活动。家长应在打开后迅速知道今天拿什么、怎么玩、怎么回应宝宝，玩后轻松记录。18～23 月为首批正式内容；0～35 月是框架能力，只有存在模板的月龄档才能开始。

不设计公开注册、宝宝信息档案、照片录音、发育测评、课程商城、社交排行、积分、连续打卡压力或管理后台。月龄只在手机保存，不展示为宝宝的能力等级。

导航：今天 / 回顾 / 设置。首次使用先引导开始计划。M1 完成首次开始、今天卡片、记录、设置与通知入口；回顾和离线完整流程属于 M2，AI 属于 M4。原型可以展示后续流程，但应使用设计审阅面板区分阶段，M1 产品界面隐藏尚不可用的入口。

## 2. 页面清单

| 编号 | 页面/弹层 | 关键内容和操作 |
| --- | --- | --- |
| A01 | 开始计划 | 输入当前已满月龄；提醒建议 19:30，可关闭；匹配可用模板；确认开始日期和连续七天 |
| A02 | 今天 | 日期、计划第几天、活动标题、材料、步骤、四类回应；可选儿歌/中文词/英语/数感；记录入口 |
| A03 | 记录反馈 | 「一起玩了 / 今天跳过」；反馈可不选，按状态显示合法标签；保存、取消与修改 |
| A04 | 本周回顾 | 玩过、跳过、未记录、未来分别显示；七天列表；同步状态；开始下一周 |
| A05 | 历史与日期详情 | 历史周列表；点日期查看当时卡片和补记；未来日只读 |
| A06 | 设置 | 当前估算月龄与手动修正、提醒开关/时间、系统权限状态；服务连接异常时显示清楚的恢复说明 |
| A07 | 无任务/无内容 | 未开始、今天不在已排计划内、计划已结束、没有匹配内容分别处理 |

| A09 | 周建议与下周确认 | 仅 M4；基础周报永远可看；建议显示依据，确认前展示只替换哪一天 |

详细行为与状态见 `docs/specs/03-安卓交互与状态规格.md`。

## 3. 内容展示要求

使用 `content/demo/demo-content-package.json` 的真实中文演示卡。主样本为「演示｜小手拍拍」，另用「演示｜球球滚过来」验证没有儿歌、英文、数感时整段省略。

信息顺序：标题 → 准备材料（空数组显示「不用道具」）→ 怎么玩 → 家长怎么说/宝宝回应 → 可选扩展 → 安全说明与参考来源。

四句回应使用「开始时 / 宝宝跟着玩 / 宝宝只是看 / 宝宝想停」等易读小标题，不显示 `whenJoins` 等字段名。英文同时给中文意思和使用时机，不要求背诵。引用用可识别的资料标题，打开外部来源时保留返回路径。

记录动作不应被长卡片埋没。可以使用底部操作区，但不得遮挡内容、系统手势区、键盘或字体放大后的文本。所有卡按字段渲染，不按主题名称分支。

## 4. 必须做出的状态

- 首次加载、请求失败重试、服务不可用、凭证失效；不能把失败显示成「没有内容」。
- 首次建周成功、快速重复点击、响应丢失后重试同一次请求、内容已更新需刷新后重选。
- 玩过/跳过/未记录的视觉区分；反馈可跳过；取消编辑不修改当前记录。
- 已在本机保存待同步、同步成功、重试失败；没有缓存时的断网提示。
- 提醒关闭、系统权限未授予、时间已过今日不补发、打卡后取消今日提醒。
- 历史补记、未来只读、今天无任务；不能将未来日期归为未记录。
- 无模板的月龄档、跨档无适龄内容、修改月龄不改变当前周。
- M4 的信息不足、模型暂不可用、旧建议失效；基础周报可继续使用。

原型需提供场景切换入口，但仅供设计审阅，不进入正式产品导航。固定时钟用设计样本中的 `referenceNow`，不得用真实当前时间造成演示状态漂移。

## 5. 视觉、触控与可访问性

设计方向是安静、温和、适合家长快速浏览。主次信息明确，中文正文自然换行；使用系统可用中文字体，避免依赖未经授权的商业字体或外链字体才能阅读。

最小触控区域按 48×48 dp 的设计目标检查；正文初始设计参考 16 sp，并验证系统字体放大到 200% 后可读、可滚动、不遮挡。普通正文与背景对比度至少 4.5:1，大字/必要非文本边界至少 3:1。颜色不能作为记录或错误的唯一提示。

组件具备语义标签、选中/禁用/加载状态。检查 TalkBack 阅读顺序、返回键、弹层焦点恢复、键盘遮挡、系统安全区域及深浅主题。设计稿应区分 dp/sp 与 Web 预览 px；原型不能证明 Flutter 语义或系统权限已实现。

不强制动画、音效或庆祝效果；如有过渡，在减少动态效果时仍清楚可用。手机画板至少核对 360 和 412 逻辑宽度，并允许长内容滚动，不以固定高度截图作为唯一交付。

## 6. 设计输入与验收

输入：本简报、安卓交互规格、OpenAPI、内容 Schema、演示包、设计场景样本、验收规格。用户凭证、服务地址由部署配置提供，设计样本不包含真实值。

交付：可点击中文原型、全部状态截图或入口、组件/颜色/排版变量、字段到组件映射、Flutter 实现说明、尚需真机验证的清单。完成 A01→A02→A03→再次打开A02 的主路径，并演示 A04/A05 的补记与 A08 的恢复路径。

## 7. 可直接使用的输入提示词
