## 4. 交回与验收

交回可点击源码及打开方式、页面状态清单与P用例结果、模拟动作说明、候选变量、组件状态、资源与许可清单、Flutter/Web交接、后端新旧对象差异和待定规则。先审低保真，再确认视觉方案。

检查360/412逻辑宽度、网页768/1280及窄屏、200%字号、深浅主题、48触控目标、实际颜色对比、键盘与焦点。HTML/React不能证明APK、TalkBack、通知、SQLite、并发同步或媒体上传已实现；这些在真实实现中另验。

缺少目标机、部署环境、确切生日、书目版本和入睡时间不阻塞低保真；不得据此伪造兼容性、参考百分位或点读能力。设计只使用虚构场景和原创话术。
