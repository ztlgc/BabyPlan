# 实施阶段与验收规格

版本v0.1；2026-11-11。本文是后续设计/开发的验收合同，不是已完成测试记录。当前只交付设计准备资料与规格。

## 1. 分阶段能力

| 阶段 | 必须交付 | 此阶段不依赖 |
| --- | --- | --- |
| M0设计与合同 | 两端设计简报、安卓页面状态、OpenAPI、数据与事务规则、虚构样本；实际设计产出另行审阅 | 可运行App或服务 |
| M1真机主流程 | 演示包导入、options、建周、current/指定周读取、列表limit=1排期发现、在线打卡、Flutter卡片与本地提醒、重复请求处理 | 完整离线队列、历史导航、基础周报、AI |
| M2连续使用 | SQLite持久化、离线重开/记录/顺序补传、冲突恢复、历史周与日期、基础周报 | 模型建议 |
| M3内容与试用 | 正式18～23月内容、同APK换包、历史快照、坏包拒绝和回滚、私人访问与HTTP/HTTPS入口、备份恢复 | 公开注册、CMS |
| M4周建议 | 单条有依据建议、家长确认后替换下周一天、失效/失败降级 | 自动换计划、多设备 |

M0规格完整不表示设计稿通过，也不表示M1已实现。M4需要另行补充建议API和数据合同；当前OpenAPI仅锁定M1/M2能力，不允许客户端调用尚未定义的建议接口。

## 2. 设计验收（原型即可核对）

| ID | 情景 | 预期 |
| --- | --- | --- |
| D01 | 首次打开并开始 | 月龄/模板/日期/提醒可理解；无公开注册；今天可见活动 |
| D02 | 有完整可选字段的拍手卡 | 材料→步骤→四类回应清楚；英文有意思和时机；安全说明可见 |
| D03 | 只有核心字段的滚球卡 | 儿歌、英文、数感整块省略，无空标题和播放按钮 |
| D04 | 玩过/跳过/未来/未记录 | 文案和形态区别明确，颜色不是唯一提示；未来只读 |
| D05 | 取消修改、切换状态 | 不误保存；played切skipped时清除want_again |
| D06 | 失败、无内容、无排期 | 三种状态不同；动作能恢复，不显示假成功 |
| D07 | 同步与修订冲突 | 分清已存本机与已同步；可选择采用服务器或确认重提本机意图 |
| D08 | 通知拒绝/时间已过 | 可继续使用，不反复索权；不声称必定准时投递 |
| D09 | 长卡片、200%字号、深浅主题 | 主要信息与操作可见，无遮挡；触控和对比度满足设计目标 |
| D10 | 阶段切换 | M1没有可点却未实现的回顾/AI；审阅面板与正式导航分开 |

原型的网络、通知与离线按钮均需注明模拟；不能把点击反馈当作持久化或真机证据。

## 3. M1接口与真机验收

| ID | 输入/动作 | 必须观察到的结果 |
| --- | --- | --- |
| B01 | 有效演示包导入 | 合法包可用；options只将有模板档作为可开始 |
| B02 | 首次按今天建周 | 七个连续家庭本地日期、稳定ID、完整快照；数据库唯一家庭日期 |
| B03 | 同requestId同载荷重试 | 首次和重放均201及原响应，数据库仍一个周七任务 |
| B04 | 同requestId异载荷 | 409 IDEMPOTENCY_CONFLICT，无额外周；缺省值按规范化合同处理 |
| B05 | 响应丢失后内容换版/跨日 | 原ID重试先重放成功结果，不因动态校验而创建新周或报新冲突 |
| B06 | 另一个请求日期重叠/日期不正确/已有未来周 | 明确409，事务回滚且无半个计划；并发请求也成立 |
| B07 | 打卡、原operationId重试 | 当前结果一条，revision只增一次；原响应可重放 |
| B08 | 同operationId改载荷、旧baseRevision | 分别返回幂等冲突/修订冲突，不覆盖当前结果 |
| B09 | 错配反馈、未来打卡、未记录写入 | 合同规定错误，状态不变；未来不能靠客户端隐藏来保障 |
| B10 | 无效凭证/其他家庭资源 | 401或隐藏归属的404，不从幂等缓存泄露结果 |
| B11 | 安卓锁屏提醒点击 | 通知最多一次、进入payload对应任务；打卡取消，改时撤旧 |
| B12 | 保存后关闭重开 | 服务器读回一致；没有联网成功前不显示已同步 |
| B13 | 当前无周但历史/未来存在 | current为null，不能把历史卡显示为今天；已排未来可查看 |

至少保留API响应、数据库查询/约束证据与目标机操作记录。截图不足以证明幂等、事务或通知去重。

## 4. M2连续使用验收

| ID | 情景 | 预期 |
| --- | --- | --- |
| C01 | 下载周后断网、杀进程再开 | 卡片和未同步意图仍在；本机可记录并标待同步 |
| C02 | 无缓存且断网 | 明确提示联网下载，不生成虚构任务 |
| C03 | 同任务离线连续修改，A发出但响应丢失，再编辑B | 先重放A，确认后发送B；旧响应不覆盖B显示 |
| C04 | 服务端修订变化 | 暂停该任务队列，保留本机意图；用户选择后新ID重提或采用服务端 |
| C05 | 补记/改记 | 归原date；recordedAt和syncedAt不替换活动日期 |
| C06 | 今天/历史/未来混合、空记录 | 四项counts总和7；今天未记可计未记录，未来不计 |
| C07 | 有待同步时查看周报 | 标识服务器统计与本机意图，M4建议生成被同步前置阻止 |
| C08 | 周时区跨日与设备换时区 | 任务日不漂移；recordsVersion/asOfDate更新；通知按周时区安排 |
| C09 | 月龄1月31日录入、2月末/3月30日/31日 | 日历月规则一致；手动修正不改变旧周；无新档内容不放宽适龄 |
| C10 | 改时、关闭/恢复权限、重开/重启 | 已投递同日不再发；过去时间不补发；已记取消 |

Android权限、系统节电、开机恢复和系统设置入口，必须在目标机上验证并记录限制，不用浏览器原型代替。

## 5. M3内容与试用验收

- 同一APK：v1排周保存旧句；导入v2改句后新周显示新句，旧周仍为旧句。
- 相同packageId/contentVersion同内容导入无副作用，异内容拒绝；坏包不改变活跃指针。
- 固定七档与边界完整；卡片引用/标签/模板适龄检查通过；正式环境拒绝demo。
- 回滚到保存的有效旧版本，只影响之后生成计划。
- 正式六主题完成台词、材料、适龄、安全与来源人工审阅；家庭试用实际使用七天并记录问题。
- 私人访问与HTTP/HTTPS入口、凭证轮换步骤、备份和恢复演练可执行；HTTP仅用于可信局域网，真实环境信息填入部署记录，不写进公共设计包。

## 6. M4准入与验收

准入前先补建议输入/输出、suggestionId生命周期、recordsVersion/目标档位绑定、确认原子性与错误合同。没有这些合同，设计可展示流程，产品不能接入实际建议操作。

样例：同活动两次want_again能引用真实记录并建议复玩；只有一条记录或全未记录时给合理的信息不足；模型失败基础周报仍可看。用户取消不改计划；确认只换下一周一天；过期内容、记录更新、目标档不匹配和重复确认均不能重写旧周或重复建周。

## 7. 验收记录模板

每次记录阶段/用例ID、日期、构建号或提交号、内容版本、设备/Android版本、部署环境、输入、预期、实际、证据和待修复项。设备型号、SDK/插件锁定版本、网络与通知限制，在首次真机运行时填写；未执行项写「未执行」而不是默认通过。
