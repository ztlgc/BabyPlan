# 内容线：活动卡和内容包怎么做

内容线负责把活动写成家长拿到就能做的卡，并交付一份通过校验的 JSON 包。无需等待 App，也不需要修改 App 代码。[18 月龄内容清单](../content/18月龄内容清单.md)里的六张主题卡和分龄例子是首批素材。

## 先交付哪一批

1. **18～23 月正式包：** 小手拍拍、球球滚过来、杯子进篮子、两只袜子、书里的小狗、小熊晚安。先排一个七天模板：小手 → 小球 → 杯子 → 小手（复玩）→ 袜子 → 小狗 → 小熊。复玩是同一张卡，家长可采用卡内的变化玩法。
2. **24～35 月下一批：** 从已用过、想复玩的主题开始，补「宝宝先选或先做、家长再跟着」的版本，再补新的七天模板。
3. **更早的月龄：** 按 12～17、9～11、6～8、3～5、0～2 月顺序补。可以先有档位、后补卡和计划；没有可用计划的档位不对外显示为可开始。

八类内容沿用：儿歌与节奏、中文词语、亲子对话与共读、生活英语、数字与数量、认知与探索、身体与手部动作、生活情绪与轮流。用标签帮助查找，**每天仍只安排一个主游戏**。儿歌、数字、英文和复玩变化按需要填，卡上没有相关内容时直接省略。

## 每张卡按这张表写

| 字段 | 填写规则 |
| --- | --- |
| `id`、`themeId`、`title` | 卡片有一个稳定编号；同主题的月龄版本共用 `themeId`。改台词保留 `id`，新增玩法版本另用 `id`。 |
| `ageBands`、`domains` | 填适用月龄档和内容标签。确认跨档仍合适的卡，可填多个档位。 |
| `materials`、`steps`、`variation` | 写家里要拿什么、一到几步怎么玩；不用道具就填空数组。可选一个复玩变化，如「让宝宝先来」。 |
| `dialogue` | 给可直接照念的四句：开场、宝宝跟着玩时、宝宝只是看时、宝宝想停时。 |
| `keywordsZh`、`english` | 中文写具体词；英文写词、中文意思、能当场说的完整短句、哪一步说。 |
| `song`、`numberPlay` | 儿歌写标题、哪一段及配合动作，可附自编口令；数字写具体数量或概念、用什么动作演示、家长说哪句。 |
| `safety`、`sources` | 写清这张卡的材料或陪玩要求，附参考资料标题和链接。 |

整理时先把话写成家长平常会说的样子。例如「小手拍拍」写成：不用道具；选《如果感到幸福你就拍拍手》的拍手段；边说「一」边拍一下；开场「你看，我拍一下——啪！」；宝宝也拍就接「你也拍啦，还想再来吗？」；只看就接「我再拍一次给你看」；想停就说「好，玩完啦」。英文写 `hands` / `clap` 以及 “Let’s clap our hands!” 和中文意思。

## 交付给开发的文件

交付一个按[字段规范](../../contracts/content-package.schema.json)制作的 UTF-8 JSON 文件。文件包含四部分：

- **包信息：** `schemaVersion` 是交接格式版本，固定 `1`；`packageId` 是稳定的包名；`contentVersion` 是内容发布序号，每版递增；`channel` 写 `release`（正式）或 `demo`（演示）。正式包统一用 `family-play-zh-cn`。
- **`ageBands`：** 档位编号、显示名、起止整月。首版使用 `m00_02`、`m03_05`、`m06_08`、`m09_11`、`m12_17`、`m18_23`、`m24_35`。起止都包含，档位连续且不重叠。
- **`cards`：** 活动卡列表，每张独立可显示。歌曲只写标题、提示和自编口令；首版不随包携带录音或视频。
- **`weekTemplates`：** 每套有 `id`、`title`、`ageBand` 和按日排列的 7 个 `cardIds`。可以重复同一张卡；编号必须在本包里存在，且适用于这个月龄档。若填了儿歌、中文词、英文或数感字段，要有对应的内容标签。

提交前照着卡玩一次：看家长是否一眼知道做什么，数量能否用实物或动作演示，英文和中文是否对得上，宝宝只观察或想停时有没有自然的接法。再运行校验脚本。脚本能查字段、档位和引用；适龄性和台词仍由内容制作人检查。

```bash
# 在项目根目录执行；需要 Python 和 jsonschema。缺少依赖时可在开发环境安装：
# python -m pip install jsonschema
python -I tools/validate_content.py content/demo/demo-content-package.json
```

正式包制作完成后再执行：

```bash
python -I tools/validate_content.py content/release/family-play-zh-cn-v1.json --release
```

第二条命令用于交付正式包时；文件由内容线制作。脚本和[演示包](../../content/demo/demo-content-package.json)可以先验证工具和格式。
