# 小芽 BabyPlan 0.1.3 真机验收卡

这份清单给实际拿到手机的人使用。先用虚构小名、示例文字和一张不含家人的照片，避免把试用数据当成正式成长档案。每项只记录实际结果；没有设备或没有等到通知时记“未执行”。

| 操作 | 预期结果 |
| --- | --- |
| 安装 `0.1.3` 试用 APK，打开“今天”，点开一项 | 能读到材料、步骤和可以直接说的话；没联网也能打开 |
| 记一项活动，再切到“轻松一天”，随后恢复 | 记录仍在；未开展的四类短活动各约 5 分钟；已记的其他活动不会消失 |
| 在“家庭 → 提醒”选一个还没到的时间，拒绝一次系统通知权限 | App 还能看活动和记录；提醒开关没有显示为已开启 |
| 允许通知后，在锁屏状态等待；另选一日把今天全部项目提前记完 | 锁屏提示实际到达时记时间；当天已做完的情况不会再通知。若系统推迟到 20:00 后，不补发 |
| 重启手机，确认次日提醒；另一次更新提醒时刻后关闭开关或退出 | 只按最后一次有效设置提醒；关闭或退出后旧提醒不响。记录 Android 版本和是否开了省电 |
| 用家长网页创建测试家庭，另一台手机用邀请加入 | 同一天活动一致；一台记备注，另一台刷新能看到；移除成员后旧账号无法再打开家庭 |
| 打开飞行模式，保存成长小记和参与备注；划掉 App 再打开，之后恢复网络 | 离线草稿和记录仍在，联网后另一端能看到；同一操作不出现两条 |
| 在账号 A 留下未同步成长记录，退出后在同一手机登录同家庭的账号 B，再切回 A | B 看不到、也不能代发 A 的私人草稿；A 重新登录后待同步记录仍在 |
| 分别更正一条测量和一条阶段观察，再移到回收站；在手机和网页查看后恢复 | 两端先移除并显示在最近删除；恢复后正文、数值、修订和删除时间一致，不复活成重复记录 |
| 从系统选图时先取消；再选一张示例图，断网时提交，之后联网 | 取消不要求整库权限；正文先留在手机；图片状态可重试，另一端收到后再显示已就绪 |
| 选图后趁系统回收 App，再回到 App 继续编辑 | Android 系统选择器返回后仍能恢复刚才选中的图片，不需要重新授权整个相册 |
| 用同一类型的 0.1.2 APK 先留下本机测试记录和待同步草稿，再覆盖安装 0.1.3 | 包名相同才是同一条升级路径；不要先卸载。打开新版后，本机记录、账号归属和待传草稿仍在 |

记录手机型号、Android 版本、APK 类型、日期和失败操作。已通过的自动化与 Windows 恢复记录在 [开发与交付验证报告](../implementation/开发与交付验证报告-2026-11-13.md)，不算作上表的真机结果。
