# 1～2 岁每日亲子活动

从满 1 岁到满 2 岁，安排 **365 天亲子活动**。每天选表里一项，跟着宝宝的兴趣玩。整套活动用家中常见物品，英语、数数和儿歌都在真实动作里顺手带一句。

| 月龄参考 | 天数 | 日常可以多做什么 |
| --- | --- | --- |
| [12～14 月龄](12-14月龄.md) | 第 1～91 天 | 一起看、听、摸；回应眼神、手势和声音；坐着或用宝宝已经会的方式移动。 |
| [15～17 月龄](15-17月龄.md) | 第 92～182 天 | 多示范简单动作，边说边指，给两个都能接受的选择，让宝宝主动试一小步。 |
| [18～20 月龄](18-20月龄.md) | 第 183～273 天 | 接住宝宝的手势或单词，再加一小句；加入简单假装、轮流、收纳和涂画。 |
| [21～23 月龄](21-23月龄.md) | 第 274～365 天 | 给宝宝多一点决定权；跟着他的玩法模仿、搭配，体验简单的先后顺序。 |

已经一岁半，可以从 **第 183 天** 开始，也可以从任何顺手的活动开始。天数是顺序编号，月龄是选玩法的参考，到了下一档可以直接翻过去，不用补课。遇到第 366 天，复玩喜欢的一项。到两岁生日当天，可以两人轮流翻家庭照片，宝宝指哪张就聊哪张；成人说一句“这是你在滚大球”，等宝宝用表情、手势或话接上。

## 一次怎么玩

1. 选宝宝清醒舒服的时候，在换衣、收拾、散步、共读里加进去。一次可以先玩 **3～5 分钟**，愿意就继续，只有半分钟也可以。这是方便家长的起步建议；宝宝全天还需要分散的自由活动和休息。
2. **先做一次，说一句，停下来等。** 伸手、看过来、发声、指一指都可以接。比如宝宝推了球：“你把球推给我了。”只看时，把动作做慢一点：“你在看，球慢慢过来。”不必追问或让孩子跟读。
3. 宝宝转开、推开、烦躁或累了，收起来：“好，我们先停。”每周最后一天预留给复玩，也可以休息。只记一件看见的事就够，例如“球停下来，他伸手拍了一下”。

儿歌用表里的短口令轻声念唱，停一下让宝宝接动作。数字由大人对着实物一件一件地说，宝宝无需记住数字。英文是可选的同场景短句，括号内是意思；家长用自己说得自然的语言多和宝宝交流。

## 材料和场地

- 成人全程在近处看护。选标明适龄、完整、无可脱落小零件、整个放不进嘴的玩具；软球用完整大球。收走纽扣电池、磁铁、硬币、吸水珠、气球、小配件、塑料袋和长绳。不用食物当玩具。玩偶检查眼睛等部件；小方巾可以遮玩具，始终远离宝宝的口鼻和颈部。
- 走、蹲、推球都在平坦、防滑、清空的地面。远离楼梯、家具尖角和车道；不拉手臂带走，不扶着孩子跳。宝宝可以坐在地上用手完成同一游戏。绘画只用适龄粗蜡笔；还会往嘴里放，就做无道具的手指画。
- 洗手是成人陪着做的日常活动，用温水并全程扶稳照看；练习倒、舀的游戏用空杯和大件材料。散步观察时成人负责避开车辆、宠物、可入口小物和积水。
- 发育里程碑是观察参考。对发育有担心、到了相应年龄没看到指南中的能力，或孩子失去了以前会的技能，可以尽早向儿保医生或儿科医生咨询，带上平时观察到的例子。

## 服务接入

服务内容包为 [`content/candidate/babyplan-daily-12-24-v1.json`](../../../content/candidate/babyplan-daily-12-24-v1.json)，由 `python -X utf8 tools/build_daily_curriculum.py` 从这四份原稿生成。包含 365 项每日玩法及原有 24 项活动的新修订，审阅状态仍为候选草稿。

- 准确出生日期：满一岁生日为第 1 天，之后每天顺序加一；闰年多出的一天复玩第 365 项。满两岁后回到后续月龄内容的原有规则。
- 只记月龄：用 `floor((记录月龄－12) × 365 / 12)＋1` 估算记录日的起点，之后按实际日期递进。因此记录 18 月龄当天从第 183 项开始。月龄档和分段是参考，不是能力要求。
- 12～23 月龄每天安排一项，预算 5 分钟；儿歌、数数和英语都是同一玩法中的可选内容，不是额外作业。轻松模式保留这一项。
- 继续使用既有七天计划和活动详情接口，不增加 HTTP 路径。今日已有的活动快照、开始记录、家长保留项和参与记录不会被新包改写。
- 材料被排除、尚未具备或活动被撤回时，不以别的活动打乱每日顺序；服务会如实返回缺项。家长可以采用卡片里的更轻松玩法或休息。

这份候选包可以在现有开发内容模式下导入和启用。私人试用和公开内容环境仍须走真实人工审读与证据工作流，导入不会自动把内容改成“已专业审阅”。
