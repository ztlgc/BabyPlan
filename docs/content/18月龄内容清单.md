# 家庭早教跟踪：18 月龄首版内容清单

这份清单确定 App 要提供的亲子活动内容，以及每张卡应具体到什么程度。家长每天看到一个生活主题，拿起家里已有的物品，就知道做什么、说什么、怎么回应宝宝。词语、英文和数量可以出现在同一个游戏里。

## 内容库要收哪些东西

| 内容 | 首批收录 | 卡片写到什么程度 |
| --- | --- | --- |
| 儿歌与节奏 | 《如果感到幸福你就拍拍手》《小星星》，以及滚球、收物等自编口令 | 写明唱哪首、用哪一段、配什么动作、在哪里停一下。家长不熟悉旋律时，可以直接念活动卡上的口令。 |
| 中文词语 | 物品：手、球、杯子、篮子、袜子、小狗、小熊。动作：拍、滚、拿、放、翻、抱。表达：再来、帮忙、不要、好了。 | 每次挑一两个在眼前用得上的词，给一句家长可以直接说的话。 |
| 亲子对话与共读 | 指图、描述宝宝正在做的事、等待回应、给一个简单选择、尊重想停止的信号。 | 写出家长第一句话，以及宝宝有动作、只看、想结束时，家长各怎么接。绘本卡写明看什么图、说哪一句。 |
| 生活英语 | `hands / clap`、`ball / roll`、`in / out`、`sock / two`、`dog / woof`、`bear / good night`。 | 每张卡给一两个词、自然的短句、中文意思和开口时机。家长用自己顺口的语言接话。 |
| 数感 | `1`（一个球或拍一下）、`2`（两只袜子）、再来一个、还有没有。 | 家长指出物品或做动作，同时说出数量。先感受数量，不设识读数字或背数的目标。 |
| 认知与探索 | 里面／外面、有／空、看得见／找一找；在实际物品上顺口说出颜色、大小、软硬。 | 给一个可操作的变化，如杯子进篮子、拿出来后篮子空了。颜色和形状跟着实物说。 |
| 身体和手部动作 | 拍手、滚球、放入取出、翻硬页书、挥手。 | 写清场地或材料、大人如何示范、宝宝可以怎么参与。 |
| 生活、情绪和轮流 | 一起收东西、选一件物品、说「不要」或「帮我」、轮流滚球、哄玩偶睡觉。 | 写明可放进哪段日常，给出一句具体回应，如「你想自己拿，我扶着篮子」。 |

首批做六张可反复使用的主题卡：**小手拍拍、球球滚过来、杯子进篮子、两只袜子、书里的小狗、小熊晚安**。一张卡有一个主玩法；儿歌、数感和英语在能自然用到时加入。同一个游戏可以隔天再玩，第二次只换一句话或换谁先开始。以几分钟为试玩的起点，宝宝愿意就继续，想停就停。

## 六张主题母卡

### 1. 小手拍拍

- **准备：** 不用道具。面对面坐着玩。
- **儿歌：** 《如果感到幸福你就拍拍手》。哼到熟悉的拍手段，拍一拍就停，等宝宝看看或动一动。不熟悉旋律时直接念这句自编口令：「小手伸出来，轻轻拍一下。停一停，等一等，想玩再来呀！」
- **今天的数字：** `1`。唱完后，单独做一次：边说「一」边拍一下，停住，再说「拍了一下」。数的是拍手的次数。
- **中文词：** 手、拍。想继续时可以加「再来」。
- **英文：** `hands`（手）、`clap`（拍手）。大人示范时说 “Let’s clap our hands!”（我们一起拍拍手吧！）；停住时可以问 “Again?”（再来一次吗？）。
- **家长说：** 「这是我的手。你看，我拍一下——啪！」然后等一等。
- **宝宝也拍：** 「你也拍啦！还想再来吗？」
- **宝宝只看：** 「你在看我的手。我再拍一次给你看。」如果注意力已经转走，就结束。
- **宝宝摆手或离开：** 「好，我们拍拍手玩完啦。」

### 2. 球球滚过来

- **准备：** 一颗大软球；在平坦、清空的地板上坐着玩。
- **节奏口令（自编）：** 「球球滚过来，停在你面前。」边念边把球轻轻滚过去。
- **数字与中文词：** `1`，拿着球说「这里有一个球」。词语是「球、滚」。
- **英文：** `ball`（球）、`roll`（滚）。递球时说 “Here’s the ball.”（球在这儿。）；往宝宝方向滚时说 “I’ll roll it to you.”（我把球滚给你。）。
- **家长说：** 「球来啦。到你这儿了。」然后等一等。宝宝碰球，可以说「你摸到球啦」；宝宝把球推回来，就说「球滚回来啦」。只看或不想接，也可以在这里结束。

### 3. 杯子进篮子

- **准备：** 一只空的、不易碎的适龄杯子和一个敞口矮篮。
- **探索与中文词：** 「进去、出来」。大人放进去说「杯子进去啦」，拿出来说「杯子出来啦」。第二次可以顺口说「篮子空了」。
- **英文：** `in`（里面）、`out`（出来）。杯子在篮里时说 “It’s in the basket.”（它在篮子里。）；取出时说 “Out it comes!”（出来啦！）。
- **家长说：** 「我放进去。你想拿出来吗？」宝宝伸手就把篮子移近，宝宝只看就说「我拿出来给你看」。不愿意继续就收好。

### 4. 两只袜子

- **准备：** 一双干净的袜子，可以顺便在收衣服时玩。
- **数字与中文词：** `2`。摆一只，说「一只袜子」；再摆一只，依次指着两只说「一、二，两只袜子」。宝宝可以拿、递或看着。
- **英文：** `sock`（袜子）、`two`（二）。边摆边说 “One sock. Here’s another. Two socks.”（一只袜子。又来一只。两只袜子。）。
- **家长说：** 「我放了一只。你手里还有一只呀。」如果宝宝递过来，说「你把另一只递给我了」；如果拿着玩，就先看宝宝怎么玩。

### 5. 书里的小狗

- **准备：** 找一本有小狗图的布书或硬页书；没有小狗，就选宝宝正看的动物，把动物名和声音一起换掉。
- **共读与中文词：** 「狗狗、汪汪」。只看一页。大人说「狗狗，汪汪」，停住等一等。宝宝指图，就说「你在看这只小狗」；宝宝发声，就顺着声音回应一句。图里狗在跑时，可以加「狗狗在跑」。
- **英文：** `dog`（狗）、`woof`（汪）。指图时说 “Look, a dog!”（看，一只狗！）；再学一声 “Woof!”（汪！）。
- **家长说：** 「你想再看这页，还是翻过去？」宝宝翻页就跟着看下一页，合上书就结束。

### 6. 小熊晚安

- **准备：** 一个没有松脱小零件的软玩偶。抱着玩偶轻轻摇一摇，家长也可以轻哼《小星星》一小段。
- **想象与中文词：** 「抱抱、睡觉」。大人示范抱玩偶，不用要求宝宝跟做。
- **英文：** `bear`（熊）、`good night`（晚安）。抱着小熊时说 “The bear is sleepy.”（小熊困了。）；挥手时说 “Good night, Teddy.”（晚安，小熊。）。
- **家长说：** 「小熊困了，我轻轻抱抱它。你想拍拍它，还是挥挥手？」宝宝只看也可以；可以回应「你在看小熊呀，它要睡觉啦」。

## 每张卡怎么记录和复用

「今天」优先展示 **准备什么 → 做一个动作 → 家长说什么 → 怎么接宝宝的回应**。儿歌、数字和英文分别标出来，家长可以直接找到。数字只在能用实物或动作演示时加入；英文可随时略过。玩偶、球等物品应适龄、没有松脱的小零件，大人在场陪同。

打卡只有「一起玩了」「今天跳过」；可以额外标「还想再玩」或「换个时间试」。AI 周回顾用记录建议下周复玩哪张卡、怎样安排更方便。学习效果不按唱了几句、会数几个数或说了几个英语词来评分。

内容依据：[国家卫健委《婴幼儿亲子交流与玩耍要点》18～24 月龄部分](https://www.nhc.gov.cn/fys/c100078/202502/19c9c6dee0274d23822f313a99ae1779/files/1741749469666_88130.pdf)建议日常交谈、耐心等待回应、看图和模仿游戏；[Head Start 的幼儿数感材料](https://headstart.gov/video/math-number-recognition-subitizing)用日常的小数量做示范；[ASHA 的多语言建议](https://www.asha.org/public/speech/development/learning-more-than-one-language/)鼓励家长使用熟悉的语言，在说话、唱歌、游戏和阅读里交流。歌曲选择、词表、脚本和主题顺序是这份家庭方案的设计，不是月龄达标表。

## 前后月龄怎么扩展

0～3 岁共用八类内容和同一批生活主题。每张卡写明适合在哪些月龄推荐、用什么材料、家长做什么和说什么。可以让同一个主题跨档复用，也可以给它配不同玩法。下表用「小手」做例子：小月龄可以听和看，之后可以模仿，愿意时再让宝宝选择和带着大人玩。月龄按已满整月划分，例如「0～2 月」是未满 3 月。表中的分组是 App 的编排方式，参考[国家卫健委分月龄建议](https://www.nhc.gov.cn/fys/c100078/202502/19c9c6dee0274d23822f313a99ae1779/files/1741749469666_88130.pdf)；两岁之后的选择、轮流和假装游戏也可参考 [CDC 的 30 月龄活动建议](https://www.cdc.gov/act-early/milestones/30-months.html)。

| 月龄 | 内容重点 | 「小手」主题的一张卡 |
| --- | --- | --- |
| 0～2 月 | 听照护者的声音、看脸 | 换尿布时，家长说「我在这儿呀」，轻哼《小星星》一句，停一停，看宝宝的表情。 |
| 3～5 月 | 来回发声、看表情和动作 | 家长张开自己的手说「小手在这儿」。宝宝发出声音，就学一声，再等一等。 |
| 6～8 月 | 留意熟悉动作、玩出现和消失 | 家长用手挡住自己的脸，露出来说「我在这里！」宝宝还看着、想继续，再玩一次。 |
| 9～11 月 | 把熟悉手势和词连起来 | 家长在出门时挥手说「拜拜！」也可以说 “Bye-bye!”；宝宝看着或挥手，都能接一句。 |
| 12～17 月 | 模仿一个动作，听简短描述 | 家长轻轻拍一次自己的手：「拍拍手，啪！」停下来，等宝宝自己决定要不要跟着拍。 |
| 18～23 月 | 儿歌配动作、听少量数词和生活英文 | 用「小手拍拍」卡。唱拍手段后，边说「一」边拍一下。选说 “Let’s clap our hands!” 或 “Again?”。 |
| 24～35 月 | 让孩子选择、轮流、假装和多接一句话 | 同一首歌可以接个小游戏：「你想拍一下，还是两下？你先拍，我跟着。」家长跟着孩子的动作数；可说 “Your turn.”（轮到你啦）。 |

小时候的卡片以家长说、唱、示范和回应为主。英文可以随家长熟悉的表达自然加入；数词也可以在看到真实物品和动作时顺口说。卡片都允许看着、少做一点、换熟悉玩法或停下来。推荐档只帮助找内容，打卡不用于决定宝宝该不该换档。

App 只需让家长填写当前月龄，在手机保存该月龄和录入日期，按过去的整月数估算并允许手动修正。跨到下一档且有合适内容时，在下周计划里建议先换入一张新卡，每天仍是一项活动。家长可以保留旧玩法、换一张卡，或改用新档的计划；当周已经排好的任务和过去的打卡不被改写。没有现成的下一档卡片时，保留仍适用的熟悉活动，提示新内容还未收录。

制作顺序：先完成并试用本家庭当前的 **18～23 月**卡；再从家长最常复玩的主题开始补 **24～35 月**版本；之后补 **12～17 月**，再向前补 1 岁以内的卡。以上表格是分龄样例，每档的完整内容包按这个顺序制作。满 3 岁后如需继续，可以增加下一年龄段的内容包。
