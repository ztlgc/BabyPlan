# BabyPlan 开发与交付验证报告

日期：2026-11-13～14（Asia/Shanghai）

## 1. 结论

BabyPlan v0.1.3 已交付手机、网页、API 与本机部署工具。本次补齐同机多账号隔离、增量同步与完整恢复、成长更正/回收/恢复、跨端墓碑和发布产物更新：

- Flutter Android 手机端已接通真实 API、SQLite、本地 outbox、离线恢复、参与记录、七天安排、成长、书架、提醒设置、照片上传状态与家庭导出。同一手机的不同账号、不同服务使用独立本机库；切回原账号可继续同步原账号草稿。
- 成长小记、测量和阶段观察支持本地优先更正、软删除、回收站恢复和远端墓碑确认；Android 系统照片选择器被回收后也能恢复选择结果。
- Fastify + TypeScript API 已覆盖账号、家庭、邀请、计划、同步、成长、媒体、导出、内容审阅/发布/撤回和管理任务。
- PostgreSQL 迁移 0001～0010 已在隔离 PostgreSQL 9.5.4 上从空库重放。恢复旧备份后，三类永久删除未复活。
- 家长网页已通过真实 Cookie/CSRF、同源 API、Chromium 和窄屏/200% 字号检查。
- 已生成私人签名 Release APK、局域网 Debug APK、公开证书和逐文件 SHA-256 清单。
- 轻松一天保留已开展项目，按可见活动计算预算；Android 接收闹钟时核验家庭日期、当天是否记完和 20:00 截止。

这证明软件闭环与自动化范围内的交付可用。它不等于已经完成真实 Android 真机、人工内容审读、双手机断网恢复或公网生产部署验收；这些边界在文末单列。

## 3. 实现范围

### 手机端

- 今天、七天预览、活动详情、参与、跳过、撤销、再玩、换项和轻松一天。
- 家庭成员、邀请、孩子年龄、家庭偏好、提醒时间与设备绑定。
- SQLite 本地事实、串行 outbox、operationId 幂等、断网重试、服务修订冲突、分页增量、删除墓碑和快照分页 410 完整恢复。
- 同机多账号分区、旧库唯一归属迁移、退出/换服务前待同步草稿导出，以及账号切换时不显示、不代发另一位家长的内容。
- 发现、家庭书架、阶段支持与观察。
- 成长小记、原话、第一次确认、身长/身高/体重测量和趋势展示；三类成长事实都能更正、回收和恢复。
- 系统照片选择后的私有副本、正文先保存、独立上传队列、重试、短时链接和遗漏状态。
- 家庭 ZIP 导出与 Android 系统文件创建器保存。
- Debug/Profile 的局域网 HTTP 支持和 Release 的运行时 HTTPS 限制。

### 服务端与数据库

- Argon2id 登录、手机刷新令牌轮转、网页 Cookie/CSRF、退出、再认证和账号恢复。
- 家庭创建、邀请、成员移除、孩子资料与家庭软删任务。
- 七天 ensure、每日六项、模式切换、换项、开始、锁定、参与、撤销和独立 session。
- 一致性快照分页、分页变更、墓碑、operationId 重放和请求冲突。快照分页遇到删除/撤回后从第一页重试。
- 成长、测量、观察、书架、家庭偏好和提醒设备；测量与观察提供回收列表和受修订保护的恢复接口。
- 私有媒体上传、文件类型/大小校验、去定位、缩略图、短时下载和清理。
- JSON/CSV/媒体 ZIP 导出与异步任务。
- 内容编辑、送审、审核证据、发布、撤回、角色隔离和历史正文快照。

### 家长网页与部署

- 真实账号登录、家庭/孩子选择、一天/七天、参与记录、成长、书架、导出和 A4 打印；最近删除统一覆盖小记、测量与观察。
- 内容工作台读取修订、证据、发布记录，并在服务端再次执行发布门禁。
- 同源 `/v2` 代理、HttpOnly Cookie、CSRF 写保护和账号不可信 API 地址校验。
- 首次安装向导可在隐藏输入管理员连接和登录口令后创建环境、数据库、初始管理员、家庭、18 月龄孩子、24 张开发内容并启动服务。
- PostgreSQL、媒体、恢复投递目录分开初始化；普通备份发现服务在线时拒绝执行维护备份。

## 5. 已发现并修复的问题

- 浏览器默认 `fetch` 丢失 Window 接收者导致 `Illegal invocation`，已绑定 `globalThis` 并加回归测试。
- 中文日期 helper 错误传递布尔 `weekday`，已修正。
- PostgreSQL 修订号以字符串返回时被误判冲突，写入路径已做明确数值化并覆盖两端读写回归。
- 360px、200% 字号下页头横向溢出，已修正并保留截图证据。
- 手机成长正文先保存、照片独立队列，避免照片失败拖垮文字。
- 家长选择陪玩者使用真实家庭成员 ID；`demo-partner` 只存在于演示模式。
- Android Release 关闭明文网络，Debug 才允许局域网 HTTP。
- 家庭只选中文、材料受限或宝宝跨月龄时，不再套不符合条件的模板。尚未开始的未来安排可重排；当天已有安排和历史保留。
- 网页照片预览、上传和导出经同源 API；同一天导出使用家庭业务日期。打印和下载不再显示已撤回的原玩法。
- 远端删除墓碑首次到达另一台手机时，旧实现没有把墓碑修订写回本机，导致随后恢复仍用旧 `baseRevision`；现已更新墓碑修订并以真实 HTTP 双手机用例覆盖。
- v6 旧库可能存在没有 `deletedAt` 的成长墓碑；升级后现在会补稳定删除时间，记录不会从回收站静默消失。
- 网页导出原先用新窗口打开下载地址，自动化环境中下载事件可能不出现且建议文件名不稳定；现在改为同页下载并明确使用 `babyplan-<任务ID>.zip`。签名入口和 ZIP 内容继续逐项验证。
