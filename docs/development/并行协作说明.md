## 唯一任务状态与编号

[开发任务清单.json](开发任务清单.json) 是主任务状态来源；详细计划见 [08-详细开发计划](../v2/08-详细开发计划.md)。主任务编号为 P0/A/B/C/D/R/CT；客户端附件中的 MB/WB、内容附件 C01～C08、接口 GAP 编号是检查项或细分索引，不另维护一套冲突状态。

状态只有 `planned / in_progress / review / done / blocked`。开始前确认依赖；结束后填写实际证据路径。仅主代理更新主任务状态和版本放行，子代理不能自行把整个阶段置为完成。

任务的 owner 表示牵头角色，不赋予其他目录的写入权。跨端任务由主代理协调文件所有者逐端接入；例如后端负责撤回协议，手机与网页呈现仍由各自代理修改。

## 目录所有权

| 文件范围 | 默认唯一写入者 | 交接方式 |
| --- | --- | --- |
| 根配置/README/计划/打包/共享类型/合同生成源/`contracts/v2/**` | 主代理 | 其他代理提交字段与行为变更建议 |
| 数据库迁移序号和共享事务定义 | 主代理 | 分配不可冲突的迁移文件名，后端编写，主代理审查 |
| `apps/mobile/**` | 安卓代理 | 包括 pubspec、路由、SQLite 生成物、测试；同一工程不并发写入/构建 |
| `services/api/**` | 后端代理 | 需要双后端时先按模块划目录，注册入口仍唯一写入 |
| `services/worker/**` | 当批后端代理 | 与媒体/导出任务同批，不能另起不明所有者 |
| `apps/web/**` | 网页代理 | 后期拆 parent/admin 前先指定共享入口负责人 |
| 候选内容生成源、审读草案 | 内容代理 | 只从源生成 JSON；不同时手改源、JSON 和原型 JS |
| 指定测试/证据文件 | 本轮指定实现者或质量代理 | QA 默认只读；明确授权测试路径后才写 |
| 正式人工审读/私人试玩事实 | 真实审读者或实际执行者 | 代理可整理原始记录，不能补造通过证据 |

同一文件同一时刻只由一个代理写。没有 Git 时按目录隔离；建立本地 Git 后可以按需要使用独立工作目录，但集成仍需验证，不把 worktree 当接口协调的替代品。

## 六个执行批次

1. **准备批**：主代理修合同；安卓代理验证构建；后端代理验证数据库；内容代理整理门禁和夹具。输出 P0，安卓工程可产生 A0 包。
2. **闭环批**：安卓负责本地库和真实页面；后端负责账号/计划/参与；第三代理做导入校验和只读检查。主代理接通双账号并验证越权与重复提交。
3. **日用批**：安卓负责离线/冲突/提醒；后端负责偏好/替换/同步；第三代理可以开始家长网页基础。若风险高则改做只读审查，不同时超额启用新代理。
4. **成长批**：安卓负责文字与图片；后端负责成长/私有媒体/导出；网页负责家长区。媒体合同、公共类型与迁移先经主代理集成。
5. **工作台批**：后端负责审阅发布撤回；网页负责管理区；安卓负责撤回呈现和升级。涉及同一移动文件的接入由安卓代理集中完成。
6. **交付批**：主代理验证恢复、删除重放和全链路；其他代理修各自范围的问题。结束的角色可转只读审查，不继续添加新功能。

R-01 基础部署/备份可在 A 后提前开展；CT 内容线从 P0 后持续并行。三条技术线都完成代码之后仍需集成与真实验收。


密钥和真实家庭资料不进入代理任务正文。需要数据库测试时使用两个虚构家庭及独立账号，不复用真实儿童记录。

## 合同变更与集成

1. 实现者提交差异建议：触发场景、当前合同缺什么、拟增字段/接口、兼容与迁移影响、对应验收编号。
2. 主代理确定规则，修改生成源、OpenAPI/Schema、共享类型与样例；记录新合同版本和受影响任务。
3. 先合并数据库/公共类型，再合并后端，再接入客户端；纯 UI 可以先开发，依赖未就绪时明确替身状态。
4. 生成工具一次由一人运行。依赖及根锁文件只由指定负责人更新，不合并多个代理各自生成的锁文件。
5. 实现者完成本模块检查；主代理查看真实差异并做受影响的集成检查。通过后再更新状态与验收证据。
6. 没有新变化或失败不反复跑完整原型测试；关注数据完整性、权限、冲突和设备行为。

## 卡住时如何继续

阻塞只绑定受影响任务。缺真机时继续自动化与服务联调，并保留真机验收；缺部署目标时继续本地与隔离环境，交可检查部署包；缺人工审读时保留工程测试内容并继续开发，不能把内容状态改成已通过。

代理不得用临时假数据隐藏错误、私自换合同、关闭权限、绕过内容门禁来使测试通过。结束前检查尚在运行的构建和代理状态，不把运行中任务报告为完成。
