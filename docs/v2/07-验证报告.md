## 3. 检查中修正的问题

1. 初版弹层依赖浏览器默认焦点行为，Tab可能走出文档焦点序列；补了弹层首尾循环与关闭恢复。
2. 未来活动直达链接刷新后可能恢复为今天；改为从计划项的日期索引恢复，记录入口继续禁用。
3. 冲突延后处理缺少可恢复入口；保存双方草稿，刷新后显示“继续处理”。
4. 已记录项保留原预算时，精简后可能超过20分钟；确认文案明确这一点，逐项显示真实预算。
5. 测量原型先只有身高趋势；补齐体重，并将卧位身长与站立身高分开，避免静默混成一条线。
6. 桌面“一周安排”按钮发生不必要断行；调整按钮布局，保留窄屏自动换行能力。

随后相应浏览器检查重新通过。截图使用清洁演示上下文；自动化输入不作为真实家庭记录交付。
