# 实施顺序与验收

以下是实际开发的验收条件；[开发任务明细](../development/开发任务明细.md) 记录目前有证据的进展。静态原型不能作为实际运行的验收证据。

2026-11-13 已细化为 [08-详细开发计划](08-详细开发计划.md) 和 [开发任务清单](../development/开发任务清单.json)。以下 A～D 及 V201～V218 编号保留；新增 P0 准备、A0 工程 APK 和 R 稳定交付检查点。内容审读与最小发布/撤回路径前置，不能等 D 的完整工作台才开始控制私人试用内容。

## 1. 实施顺序

| 阶段 | 实现目标 | 离开本阶段的条件 |
| --- | --- | --- |
| A 基础闭环 | Flutter工程、/v2服务、私人账号/邀请、一个孩子档案、内容导入、今日六项、参与记录、SQLite | 两台安卓设备登录同一家庭，一端记录另一端读到；重复提交不重复；不同家庭不可访问 |
| B 真实陪伴 | 7天滚动编排、换项/轻松模式、书架、阶段支持、本地提醒、离线与冲突 | 飞行模式重启仍能看卡和保存；联网不覆盖更晚修改；通知拒绝/省电/重启实测 |
| C 成长与网页 | 家长网页、故事/原话/第一次、测量、私有媒体、打印与导出 | 文字与照片独立恢复；其他家庭不能猜链接访问；导出含遗漏清单；本人曲线与明细一致 |
| D 内容维护与上线 | 工作台编辑/审核/发布/撤回、备份恢复、日志/监控、首批正式内容 | 草稿不可进入安排；安全撤回生效；恢复演练通过；24张卡人工审读和家庭试玩完成 |

每阶段交可安装的APK与实际环境验证记录。不先做课程商城、AI聊天、公共内容社区；也不因为它们没做好而阻塞每天陪伴的核心链路。

## 2. 功能验收场景

| 编号 | 可执行检查 | 预期结果 |
| --- | --- | --- |
| V201 | 未登录打开；邀请失效；账号恢复 | 无儿童资料泄露；邀请码只用一次；恢复后旧会话按策略撤销 |
| V202 | 两台同时请求今天与未来7天 | 每孩子每日期只有一份计划，六项总预算60；同输入可复现 |
| V203 | 某项已记录后切20分钟，再恢复 | 仅未开始项变化；原正文快照、备注与实际状态不变 |
| V204 | 缺材料、未来档无发布内容 | 给可用替代或真实空态；不越龄，不显示假数据 |
| V205 | 连续双击、超时后重试同operationId | 不重复写；同ID不同请求明确冲突 |
| V206 | 两人离线修改同一项 | 双方文本可恢复；相同结果只合并明确可合并字段，冲突需选择 |
| V207 | 同一天临时再玩一次同活动 | 独立session，不按活动ID合并掉第二次；不重复算中英同一过程 |
| V208 | 离线保存后杀进程、重启、跨午夜 | 内容/队列保留，业务日期稳定，未来不能提前记录 |
| V209 | 通知拒绝、静默、改时、重启、省电 | 只在启用设备一天最多一次；20点后不追发；不承诺精确送达 |
| V210 | 成长第一次未勾确认；照片上传中断 | 需确认或改故事；文字保存不丢，另一端不显示已收到照片 |
| V211 | 测量单位/方法/日期变化 | 显示原始事实；曲线按真实日期与方法区分；不伪造百分位 |
| V212 | 使用他人UUID读写、媒体完成、导出 | 家庭范围校验一致，404；签名下载到期、撤销后不能再发新链接 |
| V213 | 游标过期、删除同步、成员退出 | 完整重同步后不复活删除；待同步草稿有明确处理；权限失效锁定缓存 |
| V214 | 编辑改已通过稿；无权限发布 | 修改使审核失效；仅发布角色可发布审核后的固定修订 |
| V215 | 发布失败、普通回滚、安全撤回 | 失败不切活跃版本；回滚仅后续；安全撤回阻断步骤并保留历史 |
| V216 | 打印/导出包含未上传媒体 | 纸张可读；遗漏逐条列出；导出下载也验证权限 |
| V217 | 360/390/430宽、200%字、深色、键盘 | 无水平溢出、主操作可达、弹层焦点正确、状态不只靠色 |
| V218 | 备份恢复并重放永久删除 | 数据可恢复，已删资料不复活；核对RPO/RTO与媒体一致性 |
