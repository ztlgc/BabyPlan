# 界面与交互设计

## 1. 视觉方向

显示名“小芽 · BabyPlan”；短句“每天一点，一起长大”。给家长使用的纸感手册：纸白底色、橄榄绿操作、陶土色小面积重点，低饱和色区分活动类型，避免大面积童趣装饰抢占正文。

首页用“今天，一起玩点什么？”而非任务看板。视觉顺序为日期与孩子档位 → 当前活动 → 一天的弹性节奏 → 今日记录。完整内容只在详情展开。页头的家庭头像进入设置，底部四入口为 **今天、发现、阶段、成长**；“发现”内部切换活动与家中书架。比旧“书架与活动”标签短，并将低频阶段放到第三位。

设计变量见 `design-tokens.json`；Web原型使用同名CSS变量。中文采用系统字体，展示标题可以用系统宋体作温和强调，功能正文始终用无衬线；不下载外部字体。图标采用Lucide，许可随原型提供；书封是原创文字色块，不模拟真实封面。

| 背景 | #F7F5EF | #181E19 |

正文16px/1.65，辅助14px，操作16px/600，页标题28～32px；不以缩小文字容纳手机。4/8/12/16/24/32间距，卡片20圆角，按钮14，弹层24。按钮有效触控至少48，图标24。手机360～430逻辑宽；桌面1024以上双栏、1280以上侧栏＋内容；768以下重新排列。字体200%时卡片与按钮允许增高、换行。

## 2. 手机页面与行为

| 页面 | 首屏重点 | 主要动作与返回 |
| --- | --- | --- |
| M01 开始 | 一句话介绍＋当前月龄＋家庭创建/加入 | 默认18～23月可继续；不要求真实姓名/生日/照片；提醒在看到安排后再询问 |
| M02 今天 | 一个推荐活动、材料摘要、看看怎么玩 | 切换日期；完整三段可展开；换成轻松一天先展示影响再确认；已记项保留 |
| M03 活动详情 | 材料、3步玩法、开场话术、安全提示 | 一起玩了打开轻记录；今天先跳过；换一个；返回保留当天展开状态 |
| M04 轻记录 | 结果、陪伴者、可选一句话 | 默认当前成员；可选两人；不强制填分钟/照片。提交后可撤销或编辑；失败保留草稿 |
| M05 替换 | 相同类型的适用候选、材料、替换原因 | 只改所选未开始项目；已记录时提示另玩一次；已撤回内容禁止选择；可取消 |
| M06 发现 | 分类＋搜索＋短卡 | 全部/共读/运动/探索/英语/孩子主导/收尾；可直接临时玩一项，不必先塞入计划 |
| M07 家中书架 | 系列与版本确认状态 | 可登记书名/语言/是否适合当前共读；未核版本不出现具体页码和点读承诺 |
| M08 阶段 | 18～23、24～29、30～35、36月四段 | 生活表现→怎么支持→更容易/下一步→相关活动；观察与参与记录分开 |
| M09 成长 | 按时间的原话、故事、第一次 | 添加记录；第一次需家长勾选；不从打卡自动生成发育成就 |
| M10 成长编辑 | 日期、类型、正文、可选照片 | 正文与媒体状态独立；离开有未存内容时确认；照片失败可重试或移除 |
| M11 测量 | 本人历史明细与趋势 | 日期、类型、数值、单位、方法、来源；无数据为空态，只有一点只显示点，不伪造连续趋势 |
| M12 家庭与设置 | 家庭成员、提醒、偏好、数据 | 邀请、提醒开关和时段、退出、导出；更改权限时重新验证；真实销户独立危险确认 |
| M13 本周 | 七天主题与活动摘要 | 查看未来只读安排；未开始项可调整；历史补记限真实日期，不生成欠账 |

原型的演示面板在手机外：可切换在线/离线/冲突/错误/空内容和字体/主题。产品内只出现用户能理解的恢复信息，不出现operationId、schemaVersion、JWT或“HTTP 409”。

## 3. 家长网页

侧边导航：陪伴安排、家中书架、阶段路线、成长时光、家庭设置。一天/一周在同一页面切换；主栏显示安排，右栏展示选中活动的材料和步骤，避免打开很多独立页面。打印入口在周视图，不放成主要导航项。

书架采用文本封面＋列表，编辑时先改家庭备注，不覆盖全局书目版本。成长页可筛原话/第一次/故事/测量；导出前预览范围和未上传项。窄屏侧栏折为顶部导航；打印隐藏导航、工具栏与操作，保留标题、日期、材料、活动预算和说明。

## 4. 内容工作台

与家长区分开入口和权限；导航为内容库、审核、发布记录、来源。内容库不展示家庭使用统计和儿童照片。编辑页左侧结构化内容、右侧家长卡片预览，减少“写得很长但手机放不下”的问题。

草稿 → 送审 → 通过/退回 → 发布前核对 → 已发布 → 撤回。审核固定检查正文变化、来源范围、材料安全、适龄理由、英语和版权。修改已通过版本必须回到草稿重新审。发布确认列出内容项、版本、预计影响和历史保护；发布失败保持原活跃版本。安全撤回显示原因并阻断后续推荐，不能仅做绿色“已下架”提示。

## 5. 关键状态与可执行文案

| 状态 | 文案 | 动作 |
| --- | --- | --- |
| 初次尚无安排 | 今天的安排还没准备好。 | 准备今天；失败可重试，不当作完成 |
| 没有适龄内容 | 这个阶段暂时没有可用内容。 | 查看已有活动与内容范围，不自动降龄 |
| 离线有缓存 | 当前离线，下载过的玩法仍可查看。 | 查看待同步记录 |
| 离线无缓存 | 这一天还没下载到手机。 | 返回已下载日期；联网后重试 |
| 保存本机 | 已保存在这台设备，联网后继续同步。 | 查看记录；不写“妈妈已收到” |
| 保存失败 | 这次没有保存成功，刚才写的内容还在。 | 重试、复制文字 |
| 修改冲突 | 另一位家长刚刚更新了这条记录。 | 显示本机/另一方两份；合并保留、采用其中一份；取消不丢草稿 |
| 没有照片权限 | 可以只保存文字，也可以重新选一张照片。 | 保存文字、打开选择器 |
| 上传失败 | 故事已经保存，这张照片还在本机。 | 重试、移除这张；另一设备只见占位 |
| 提醒关闭 | 提醒未开启，仍可以随时打开今天。 | 用户主动点开启；拒绝后不循环弹权限 |
| 安全撤回 | 这个玩法已停止推荐，请先换一个。 | 原因、替换；历史记录保留，旧步骤不可继续执行 |
| 今日跳过 | 今天先到这里，明天重新开始。 | 撤销；不产生补做列表 |

## 6. 交互细节

弹层使用原生dialog语义，焦点进入、Tab限制在弹层、Esc取消、关闭后回到触发者。长表单有明确标签与就地错误，不仅变红。保存中禁止重复提交，成功才关闭；取消未改表单直接关闭，改过的成长正文先确认。

“一起玩了”不代表玩满预算或掌握能力；实际时长可不填。成长记录默认家庭可见，媒体默认私有。“家长甲/乙”只用在演示数据说明中，产品演示显示“我/另一位家长”或昵称。

不提供定时自动播放、计时倒数、闪动奖励。动效120～180ms且尊重减少动态设置；焦点清晰，文字和状态不能只靠颜色区分。

## 7. 从旧低保真改动的原因

旧N02一屏接近一张完整卡，全天需长距离滚动；新首页将“执行一项”与“浏览整天”分层。旧页面反复出现演示免责声明与接口状态；新原型将说明移到外部评审框，产品文案保持自然。旧手机/家长/后台类似同一组表单；新设计分别服务即时陪伴、全局整理与审核发布，保留同一名词与内容结构。
