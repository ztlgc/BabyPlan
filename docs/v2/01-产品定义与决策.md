## 2. 产品目标与范围

核心使用循环：**看今天 → 看一项 → 放下手机陪玩 → 可选记录 → 下次更合适**。

首页不展示分数、完成百分比、连胜天数、排行榜。活动是给家长的提示；不设计宝宝自行看屏幕的游戏。不会因为跳过而补发催促，也不让家长必须上传照片证明陪伴。

首批内容聚焦18～23月；阶段支持覆盖18～23、24～29、30～35月及36月衔接。推荐档是产品组织方式，不是官方逐月能力标准。没有该档可用内容时显示真实空态，不伪造跨龄推荐。

保留：今天、多项安排、替换和精简、共读/活动库、已有书架、家庭协作、阶段支持、成长故事和测量、打印导出、内容审核版本管理。暂缓：公开注册、付费课程、社交广场、成长排名、自动医学解释、点读笔控制、音视频课程、自动AI诊断。AI不是核心链路依赖；可先作为编辑助手，输出仍经过审阅。

## 3. 一天如何安排

| 时段 | 默认窗口 | 内容 | 时间预算 |
| --- | --- | --- | --- |
| 晚饭前 | 16:00～17:15内任选 | 运动15＋动手探索10 | 25分钟 |
| 晚饭后 | 18:30～19:20内任选 | 中文共读10＋英语互动10＋孩子主导5 | 25分钟 |
| 睡前 | 原有睡前流程 | 孩子选择的熟悉内容、安静复玩与道别 | 10分钟 |

六项是供选择的素材，不是六次必须完成的训练。时长为可拆分的家庭预算，不用于计时、验收或发育判断。睡前仍不知道几点，因此只用相对时间，不杜撰19:50入睡。轻松一天保留中文共读、运动、探索、英语各5分钟；原记录不丢失，被隐藏的未开始项目可恢复。

“现在这一项”的选择：当前时段首个未记录项目 → 当前时段已结束时选下个时段首项 → 所有项已处理则显示“今天的陪伴，照自己的节奏”；不是强制状态机。家长可直接点任意项目。不自动填“实际分钟”。

## 4. 对旧17项待决策的处理

| 旧编号 | 本轮决定与理由 |
| --- | --- |
| Q01 身份 | 私人部署邀请制；邮箱＋密码、管理员一次性建家庭；管理员可设置4～32位一次性邀请码或由系统生成高熵令牌，24小时失效且仅存摘要；新用户可在网页或App凭有效邀请创建账号，已有账号登录接受；恢复用部署管理员发一次性重置链接。无邮件服务时由管理员安全交付链接，不开放匿名注册 |
| Q02 权限 | 家庭owner管理邀请/移除/导出/删除；caregiver可安排、记录、编辑本家庭记录并留审计；不设置谁必须陪。内容角色editor/reviewer/publisher另授权，默认看不到家庭私有资料 |
| Q03 年龄 | 首次可选“当前月龄＋录入日期”，生日可选；首版一个孩子，表结构允许多个。18个月是演示假设；没有精确生日不显示精准百分位 |
| Q04 编排 | 固定规则优先；每天后台补足未来7天，打开App时补缺；同一天唯一；家长锁定、已开始和有记录项保护。来源、安全撤回优先于锁定 |
| Q05 提醒 | 三个弹性时段；默认建议16:00附近一次，由家长主动开启；20:00以后不补发。每账号只指定一台提醒设备；夫妻各自可开关，首入默认只建议创建者开启 |
| Q06 记录 | 每个计划项有一条共享参与摘要；再次独立开展作为新session，不能按活动ID全局合并。陪伴者数组与addedBy分别保存，补记真实日期 |
| Q07 并发 | 客户端生成operationId；共享摘要用revision乐观锁。首次同时记录相同结果可合并参与者且保留各自备注；状态/备注冲突返回409，展示双方再选择 |
| Q08 媒体 | 私有对象存储；正文先存、照片后传，失败不丢故事。系统照片选择器，只读取所选照片；不自动上传整个相册。上传就绪前不向其他设备显示“照片已同步” |
| Q09 测量 | 身高cm、体重kg；分别记录测量日期、方法、来源。首版仅本人趋势和明细，不上线医学百分位；未来参考曲线需单独审核标准、性别、年龄、方法与授权 |
| Q10 导出 | 家长网页打印A4；异步导出JSON＋CSV＋已上传媒体ZIP；可筛日期和记录类型。离线照片列入遗漏清单，不悄悄丢失；下载链接15分钟失效 |
| Q11 发布 | 草稿→送审→退回/通过→发布；版本不可变。家庭试用允许同人多角色，但必须明确自审且留记录，不伪造独立审核；公开发布前要求独立审阅 |
| Q12 撤回 | 普通修订只影响未来未锁定未开始项；安全撤回禁止继续开展，即使快照存在也加阻断提示；保留历史记录，提供替换。离线无法获知新撤回，联网优先刷新撤回清单 |
| Q13 书目 | 已有系列保留原名，“拼英认知系列”不改字；版本未知标注待核。通用共读卡不依赖特定页码；不承诺点读兼容，不扫描或传播书页 |
| Q14 离线 | Android下载未来7天及近30天记录；离线保存参与、故事和测量；换活动仅能选已缓存合格项并待同步。邀请、成员权限和发布操作必须在线 |
| Q15 语言 | UI简体中文；英语卡含原句/中文意思/使用时机/动作；音频暂缓，父母自己说；不做英语词数目标 |
| Q16 隐私 | 家庭私有、最少采集；content角色无家庭数据访问。删除记录先回收30天，可立即永久删除；账号/家庭删除单独确认，备份保留最多30天并以墓碑防恢复复活 |
| Q17 阶段 | 18/24/30/36月来源节点明确区分；转译为家庭支持建议，不做诊断、达标率或完成度；发展倒退或有疑虑时提供专业沟通入口 |

## 5. 旧方案如何迁移

v1是未投入生产的设计，不需要假定有真实用户数据可迁移。保留旧文件、演示包和截图，不原地转换虚构记录。新内容 `schemaVersion=2`，新接口 `/v2`，两个版本分别验证。

| 旧设计 | 新设计 |
| --- | --- |
| Week＋每日Task | DayPlan→Block→PlanItem，后续7天滚动生成 |
| 一个familyCredential | 每个用户和设备会话；每请求校验家庭成员身份 |
| 一日一卡、19:30提醒 | 六项素材、三弹性段、建议16:00一次提醒 |
| 月龄仅手机保存 | ChildProfile保存年龄精度与基准日，家庭共享；生日可空 |
| 一条checkIn | 计划项参与摘要＋可独立的临时session，陪伴者/添加者分离 |
| 卡片更新不影响历史 | 保留不可变快照；另加安全撤回层，不能因历史快照而继续推荐危险内容 |

## 6. 观察产品是否有用

家庭试用看四件事：家长能否在30秒左右理解一个玩法；是否经常需要找缺失的道具；记录是否负担过重；两人是否能接上对方的陪伴。30秒是可测试的设计目标，尚未测量，不是已达成指标。采用访谈和本地使用观察，不默认上传儿童画像或第三方行为分析。
