# BabyPlan：把今天的陪伴准备好

设计基线 v2.0 · 2026-11-12 · 本轮完成产品、内容、交互与技术设计，不是已安装的 App。

2026-11-13 后续：已制定 [详细开发计划](08-详细开发计划.md)，用44项主任务组织开发、子代理分工和验收。可直接打开 [阅读版](../../deliverables/v2/开发计划.html)。产品实现仍未开始。

你打开手机，看到一个现在就能开始的小游戏：拿什么、怎么玩、怎么接宝宝的话。玩完可以轻轻记一下；不想记、不想玩、换一本书，都可以。一天的安排已准备好，爸爸妈妈不用自己备课。

## 先看这三个地方

1. 打开项目根目录的 **打开设计.html**，查看设计总览。
2. 进入 **手机体验**：今天 → 看看怎么玩 → 一起玩了 → 记录；也可以换活动、切到轻松一天、查看阶段和成长。
3. 进入 **家长网页 / 内容工作台**，看一周安排、书架整理、成长记录与内容审核流程。

想先读具体内容，可以打开 [24张活动手册](../../deliverables/v2/活动手册.html)，里面有完整话术和首周安排。

原型使用虚构数据。操作只保存在当前浏览器；切换“离线”“冲突”和角色是演示，不代表真实家庭同步、通知或照片上传已经实现。

## 这次做了哪些决定

| 要解决的事情 | 新设计 |
| --- | --- |
| 不知道今天陪宝宝做什么 | 自动准备一天，首页只突出当前一项；完整一天分晚饭前、晚饭后、睡前 |
| 有一小时，却凑不出连续时间 | 六个可拆分内容项，预算25＋25＋10分钟；20分钟的“轻松一天”随时可选 |
| 不知道怎么教一点东西 | 每项说明一个支持方向，给动作、中文回应和少量英文；不用考试或背词 |
| 宝宝喜欢绘本 | 每天保留共读与熟悉内容复玩，优先家中已有书；版本不明也有通用共读法 |
| 爸妈轮流陪 | 一个家庭共享安排；陪伴者与记录者分开，冲突时保留双方文字 |
| 想记住成长 | 原话、小故事、第一次、照片与测量分开记录；日常参与不会自动变成“掌握了” |
| 忙了一天没做 | 没有欠账、补做任务或连续打卡压力，第二天正常开始 |

“小芽”是本次提出的中文显示名，技术项目名仍是 BabyPlan。主视觉采用纸白、深橄榄绿和陶土色，像一本安静的家庭陪伴手册。不是已取得用户品牌确认。
