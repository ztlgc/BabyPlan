# BabyPlan 儿童内容与书目研究笔记

调研日期：2026-11-11。用途：支持产品讨论与内容选题，不是已审核发布的儿童课程、发育筛查或购书必选清单。当前家庭已确认孩子处于18～23月龄。

## 1. 调研结论与来源使用规则

- 现有六张卡足以验证展示与记录流程，不足以代表完整的月龄内容体系。儿童需要重复探索；内容不足与允许重复是两回事，不能靠每天推新来替代复玩。
- 先覆盖动作、沟通、认知、情绪关系和日常自理，再叠加歌曲、阅读、数量和可选英语。英语属于语言环境，不是单独的发育领域。
- 书籍作为独立资源管理，并与活动按主题关联；优先匹配家里已有或可借的书，推荐不等于要求购买。
- 权威里程碑、专业实践、教育流派、书商推荐的证据强度不同。书目作者/出版社可以核验，精确到几个月的阅读建议通常是编辑判断。
- 所有“更易/基础/挑战”玩法都是产品设计建议，不是经过试验验证的月龄达标任务。正式发布还需要逐卡人工审阅和家庭试玩。

### 2.2 分龄内容方向

以下以18、24、30月CDC节点为锚；右侧玩法为设计转译。表内概括不能直接替代原始清单。

| 维度 | 18～23月 | 24～29月 | 30～35月 |
| --- | --- | --- | --- |
| 大运动 | 独走；提供走停、蹲起取大物、滚大软球 | 跑、踢球、走台阶；提供转向和宽目标滚球/踢球 | 双脚离地跳；提供走停跳的简单变化 |
| 精细动作 | 涂鸦、尝试用勺；提供装取、扶碗、翻硬页 | 双手分工、盖子/开关操作；提供扶容器取盖 | 转动大旋钮、逐页翻书；提供完整大容器拧转与自由画线 |
| 语言 | 尝试说爸爸妈妈外至少3个词，理解不用手势的一步指令；成人扩展词语 | 至少两个词组合、指图与身体部位；扩展动作短句 | 约50词、含动作词的组合；说谁在做什么，不背词考核 |
| 认知 | 模仿家务、按用途玩物品；提供装取与简单假装 | 将两件玩具组合；给娃娃端饭、明显特征配对 | 替代性假装、两步指令、颜色指认；提供简单两步情境 |
| 社交情绪 | 回看照护者、指有趣事物、共看几页书；提供共同关注与短暂轮流 | 注意他人难过、看成人反应；命名感受并提供安抚 | 同伴旁玩且有时一起玩、展示自己；合作收拾与请求帮助 |
| 自理 | 手拿食物、勺与敞口杯尝试、洗手穿衣参与；递毛巾、伸袖 | 用勺；继续支持盥洗与穿脱，依准备度了解如厕 | 脱部分宽松衣物、熟悉日常程序；提供两步收拾 |

未记录不等于不会，活动不参与不等于能力缺失。已经获得的能力倒退、家长持续担忧或节点条目未出现时，建议与儿保/儿科人员沟通；App不自行诊断。

## 3. 内容领域和设计原则

建议面向家长的八个入口：歌谣与节奏、日常沟通、亲子共读、艺术与感官、数量与空间、探索与动手、身体运动、生活与关系。后台另标主要发展目标与次要目标，语言设中文/英语/方言等属性。独立检查精细动作、艺术、情绪共同调节、同伴交往和自理是否长期遗漏。

| 原则 | 活动卡的实现 | 来源与边界 |
| --- | --- | --- |
| 一次只增加一个小挑战 | 更易/基础/挑战；先观察，再用最少帮助 | [NAEYC脚手架与22月案例](https://www.naeyc.org/resources/pubs/yc/may2017/rocking-and-rolling-empowering-infants-and-toddlers%20) |
| 真实生活、动作拆小 | 擦桌、放餐巾、收衣；示范后等待 | [AMI前三年独立性](https://montessori-ami.org/node/8934)；流派实践，非优效试验 |
| 允许反复和拒绝 | 家长可换卡、复玩、结束；不设敏感期倒计时 | [AMI术语表](https://montessori-ami.org/node/2170)主要面向3～6岁，低龄应用是设计转译 |
| 观察而非持续干预 | 安全空间、等待孩子尝试、照护时邀请参与 | [RIE原则](https://rie.org/category/educaring-principles/)；不把RIE与Pikler完全混同 |
| 记录过程，允许多种表达 | 纸盒可装、推、敲；不要求统一成品 | [Reggio Children价值观](https://www.reggiochildren.it/en/reggio-emilia-approach/valori-en/) |
| 数量用实物承载 | 每碗一个、一人一条、大小、里面外面 | [NAEYC婴幼儿数学](https://www.naeyc.org/our-work/families/math-talk-infants-and-toddlers) |
| 卡片只是日常入口 | 成人看卡后放下手机，不把5～15分钟当全天剂量 | [WHO2019指南](https://www.who.int/publications/i/item/9789241550536) |

WHO2019：1～2岁每天累计至少180分钟各种强度身体活动，睡眠含午睡11～14小时；12～23月不建议久坐屏幕时间，2岁不超过1小时且越少越好。来源：[WHO官方解读](https://www.who.int/EN/news-room/detail/24-04-2019-to-grow-up-healthy-children-need-to-sit-less-and-play-more)。

AAP2016媒体小时数不能标为最新：本轮另外发现[AAP2026新政策](https://publications.aap.org/pediatrics/article/157/2/e2025075320/206129/Digital-Ecosystems-Children-and-Adolescents)及[官方新闻](https://www.healthychildren.org/English/news/Pages/creating-a-child-friendly-digital-world-AAP-releases-new-media-recommendations.aspx)，具体正文未完成核验，因此不引用其数值建议。

## 4. 44项居家活动选题池

以下为基于CDC家庭建议、托育大纲、NAEYC日常数学与脚手架原则的原创编排，不是44项分别经过干预试验的课程。每次只选一个目标；5～15分钟只是可选窗口，随孩子意愿结束。材料数量和时长须试玩后调整。

通用材料要求：成人近距离陪同，物品完整且适龄；无小零件、豆米硬币、气球、塑料袋和长绳；地面空间稳定清空。常见家庭物品也需逐卡检查，不承诺零风险。

## 7. 共读方法与证据边界

[爱荷华大学阅读研究中心PEER/CROWD文章](https://irrc.education.uiowa.edu/blog/2017/01/dialogic-reading-having-conversation-about-books)已成功读取全文；Reading Rockets对应页403，不能声称正文已读。

- PEER：Prompt邀请回应 → Evaluate自然确认 → Expand多加一点信息 → Repeat再给使用机会。例：指鱼在哪里 → “你找到了” → 孩子说鱼，成人说“小鱼游走了” → 再找一次；接受手势，不机械复述。
- CROWD：Completion熟悉句填空、Recall回想、Open-ended自由描述、Wh谁/什么/哪里、Distancing联系生活。18～23月优先眼前可见的指认与拟声；回忆、抽象联系随理解程度调整，不连续盘问。
- [WWC美国教育部审查](https://ies.ed.gov/ncee/WWC/InterventionReport/135/Published)：对口语语言有正向效果，对语音加工未发现可辨识效果。样本主要为学前儿童，不能宣称18月必然提前识字。
- [Whitehurst等1988研究DOI](https://doi.org/10.1037/0012-1649.24.4.552)：本轮未读到原文全文，不引用精确效果数字。
- [Read Aloud每日15分钟倡议](https://www.readaloud.org/downloads/21daychallenge/21DayChallenge_parenthandout.pdf)：15分钟是推广目标，不是最低有效阈值；产品可从每次2～5分钟、每天几次起步，允许只看几页。
- [AAP家长共读建议](https://www.healthychildren.org/English/ages-stages/baby/Pages/how-to-share-books-with-your-baby.aspx)：共读可跟随孩子兴趣，不要求读完整本。
- [押韵词学习研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3930864/)主要为2～4岁小样本实验；不能据此外推中文18月“提升智力/音素意识”。
- [Harvard18～36月执行功能活动PDF](https://developingchild.harvard.edu/wp-content/uploads/2024/10/Executive-Function-Activities-for-18-to-36-month-olds.pdf)：搜索确认原件，工具无法解析PDF全文；不引用未经核实的效果量。

产品化可从三件事开始：活动绑定家中已有书和两三条可选回应话术；每周自选一本反复读但不强制完成；每次共读可留一条喜欢的画面/孩子原话，家长选择后进入成长档案。记录不自动转成发育评分。

### 11.5 双语依据和时间预算

本轮[AAP多语言问答](https://www.healthychildren.org/english/ages-stages/gradeschool/school/pages/7-myths-facts-bilingual-children-learning-language.aspx)只抓取到标题；旧[ASHA多语言页](https://www.asha.org/public/speech/development/learning-more-than-one-language/)跳转首页。检索摘要可提供线索，但不据此引用精确词汇量对比或为某种固定中英比例背书。

本项目建议的每日约10分钟英语是可调整的家庭安排起点，不是最低有效剂量；循序渐进依据兴趣、理解与亲子互动，不与CDC年龄节点绑定。家庭已确认父母可以自己读英文，因此英语卡以原句、中文意思、时机和动作为主，音频与点读作为可选项而非前提。

1小时纯亲子预算示例为：中文共读10、运动15、动手10、英语10、孩子主导的共同游戏10、复玩收尾5，合计60分钟；各块可拆分，父母填写记录与生活洗漱不计入。由于家庭把1小时分散在16:00～20:00，产品改为三段弹性安排（下午/晚饭后/睡前），不设固定钟点与倒计时；晚间段只放安静内容，晚饭时间不计入互动。
